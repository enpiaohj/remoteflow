# RemoteFlow v0.30.0

发布日期：2026-11-04

会话返回入口显示具体会话与账号详情，新增周期更新提示和会话菜单电源操作。
本版本仅发布 Windows（win-x64）；未含 macOS 产物。

## Added
- 会话标签菜单新增「关机…」「重启…」：支持 SSH Linux（root 或免密 sudo）及 VMware 控制台的正常来宾电源操作；操作前确认目标及影响范围。普通 RDP / VNC 不显示无可用管理通道的操作。
- 自动更新开启后，在启动后及每隔 4 小时检查新版本；版本号旁显示下载入口，可立即下载或选择「本次不再提示」。下载、校验及待重启沿用原更新流程。

## Changed
- 移除标题栏右侧返回按钮；折叠会话入口在页面态显示「返回 会话名称」，名称后附会话数，主体直接返回，右侧箭头独立展开会话列表。
- 会话标签与返回入口的悬停详情包含名称、协议、主机端口、本次连接使用的账号和状态；仅保留展示所需的非 Secret 账号元数据。
- 自动检测暂时失败时保留已发现的新版本，已下载待重启时不再自动检查；「本次不再提示」仅作用于当前程序运行期间，关于页仍可手动更新。

## Upgrade / Rollback
- 从 v0.29.0 升级：先正常退出旧版，再运行本版 EXE；ZIP 解压后包含同一份 EXE。本版未修改 SQLite Schema、配置字段及凭据保险库格式，沿用现有连接和设置。
- 升级前建议在程序完全退出后备份 `%LOCALAPPDATA%\RemoteFlow`；使用 `REMOTEFLOW_DATA_DIR` 时备份对应目录。凭据保险库受 Windows 用户保护，目录备份不能代替跨设备的加密备份导出。
- 回退：正常退出 v0.30.0，运行保留的 v0.29.0 EXE。如需恢复升级前的数据，先另行备份当前数据，再恢复原备份；不要直接覆盖仍在使用的数据目录。
- 自动更新开关沿用原设置，默认关闭；关机 / 重启对整台远程设备生效，操作前应保存工作。

## Known Issues
- 远程关机、重启仅以替身测试验证目标检查、确认及请求行为，未在真实远程设备执行；SSH 设备需支持 Linux `shutdown` 命令，VMware 正常电源操作需运行 VMware Tools。
- 实际新版本下载及退出落地未执行；周期调度、提示忽略和下载互斥等状态行为已通过替身服务测试覆盖。
- v0.29.0 记录的 DPAPI 并发写入测试偶发失败，本次完整回归未复现；未将其视为已确认修复。
- macOS 端未构建、未运行验证；本版未含 macOS 产物，Windows 产物未签名。
