## [0.27.3] — 2026-10-27

界面打磨：连接工作台的筛选与详情栏、批量栏、左侧导航栏与标题栏、首页，并让托盘悬停提示显示详细信息。
本版本仅发布 Windows（win-x64）；未含 macOS 产物。

### Added
- 托盘图标悬停提示显示详细信息：第一行是产品名与版本号；有会话时汇总各状态的会话数
  （已连接 / 连接中 / 异常）并列出最多 3 个会话名（超出写「另有 N 个」）；没有会话时给出一句操作提示。
  整段不超过系统托盘提示的 127 字符上限。
- 连接工作台：勾选主机后，批量栏最左边新增「批量连接」主按钮（原先只能到页头「批量操作」菜单或「更多」里找）；
  批量栏其余按钮、页头「批量操作」也都补了图标。
- 连接工作台：列表新增「分组」列；点击列头「名称 / 协议 / 最近连接」可排序，当前排序列带方向箭头；
  协议 / 标签 / 状态任一筛选偏离默认值时出现「清除筛选」。
- 左侧导航栏：「连接工作台」图标上显示已打开的会话数角标（有中断或失败的会话时角标转红）。
- 详情栏：近 10 次连接的柱状图上方新增一行「N 成功 · N 失败」摘要；动作行新增「传输」按钮（文件传输，VNC 主机置灰并说明原因）。

### Changed
- 连接工作台筛选：协议 / 标签 / 状态 / 排序改为浅色胶囊，写作「协议 全部 ▾」（字段名在前、值在后），
  选了具体值整颗胶囊变品牌色；下拉首项统一为「全部」，状态选项简化为「在线 / 离线」。
  「最近连接」视图的时间范围（今天 / 近 7 天 / 全部）由分段按钮改为同款胶囊。
- 凭据页：类型筛选改为同款胶囊并带「清除筛选」；搜索框限宽 440；「批量选择」图标移到筛选条末尾，与工作台一致。
- 连接列表：在线 / 离线 / 探测中只显示小圆点加文字，已连接 / 连接中 / 异常才用带底色的胶囊，需要注意的行更醒目；
  各列间距由 12～16 放宽到 28 像素；列头「在线」改为「状态」。
- 详情栏：名称行右侧为星标与「⋯」（复制地址 / 收藏 / 创建副本）；动作行为一行三个等宽图标按钮「编辑 / 测试 / 传输」
  （完整名称在悬停提示里）；有活动会话时主按钮由「打开会话」改为「切换到会话」，与右键菜单叫法一致。
- 菜单命名统一：凭据右键「用此凭据新建主机连接」（含「引用账户 / 引用名称」两级子菜单）改为「新建连接」，
  直接引用该凭据、连接名预填为账户名；两页空白处右键的「新建主机连接」改为「新建连接」；
  批量菜单「移除标签…」去掉省略号（它是子菜单）、「删除所选」改为「删除所选项」，批量连接统一叫「批量连接」。
- 首页：标题栏右侧改为三个指标块（连接 / 已连接会话 / 收藏），取代原来的统计文字行；
  已连接的「最近连接」卡片不再整块变蓝（避免像被选中），由图标右下角蓝点与卡内「已连接」胶囊表示；
  去掉底部重复的「管理收藏」「查看所有活动」入口和不可操作的「安全提示」条。
- 左侧导航栏：选中项为浅底加左侧品牌色竖条；选中会话时整列收起；移除独立的「关于」图标
  （「关于」与更新入口已在「设置」页选项卡，见 0.27.1）。

### Fixed
- 标题栏左上角像拼接：图标栏外框跨过标题栏那一行，右边框线与栏底色把 Logo 和产品名切成两块，
  内容区圆角处还多出一截线、露出一块白色缺口。现在标题栏、Logo 与图标栏同色连成一个外框，
  图标栏不再自带右边框线（只留内容区卡片自己的描边）。

### 安装与升级
- 退出旧程序后运行本版本；亦可使用应用内更新。自包含，无需安装 .NET。
- 无数据库迁移。共享层（Presentation）改动均为新增 / 内部调整，保留了 macOS 版仍在使用的成员（如首页「安全提示」相关属性），
  macOS 版尚未构建验证。
