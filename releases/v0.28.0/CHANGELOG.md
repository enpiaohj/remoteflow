## [0.28.0] — 2026-10-29

新增「虚拟化」工作台：管理 ESXi 主机 / vCenter，在应用内直接打开虚拟机控制台。
本版本仅发布 Windows（win-x64）；未含 macOS 产物，虚拟化工作台目前仅 Windows 版提供。

### Added
- **虚拟化资源来源**：添加 ESXi 主机或 vCenter 作为管理来源（证书指纹固定，凭据走 DPAPI 保险库）。
  虚拟机实时读取、**不写入普通连接列表**，不会与已用 RDP / SSH 添加的同一台机器重复。
- **虚拟机管理**：列出虚拟机（客户机系统、IP、CPU / 内存、运行时长、状态），按状态筛选与排序、搜索；
  电源操作（开机 / 来宾关机 / 来宾重启 / 挂起 / 强制关机 / 强制重置）与快照管理（创建 / 恢复 / 删除，含层级与当前快照标记）；右键菜单与详情面板。
- **内嵌控制台**：原生 RFB over WSS（复用现有 VNC 库，不依赖 VMware 控制台 SDK）；支持分辨率档位
  （自适应 / 1280×720 / 1024×768 / 800×600 / 保持不变）、Ctrl+Alt+Del、更平滑的缩放，VMware Tools 运行中的虚拟机自动请求分辨率。
- 侧栏角标把「连接会话」与「虚拟机会话」分开计数与提示中断。
- **连接工作台空状态**：按场景区分——首次使用、空分组、收藏为空、最近连接为空、搜索 / 筛选无结果、加载中；
  各自给出对应入口（新建连接 / 前往设置导入 CSV / 浏览所有设备 / 一键重置搜索与筛选，保留当前分组与排序）。
- 虚拟化工作台空状态同样按场景区分（未添加来源、来源无虚拟机、无匹配、读取中、读取失败可重试 / 编辑来源）。

### Changed
- 虚拟化工作台视觉与连接工作台统一：紧凑页头、顶部搜索、细分隔线、高密度列表；窄窗口时详情移到列表下方，可选列自动收起。
- 来源编辑与快照对话框：固定标题与底栏、正文可滚动，小屏幕与放大字体下仍能点到保存 / 取消；长快照名称不再挤出布局。

### Fixed
- ESXi 控制台鼠标指针残影：连接后补发完整 SetEncodings，声明 VMware 光标扩展，服务器不再留下合成指针。
- VNC 会话不再记录按键内容。
- 最近连接页的搜索框不生效。
- 来源切换时旧请求结束后覆盖新来源的加载状态；读取失败时静默刷新被伪装成空状态。
- 快照创建 / 删除后快照数量文案不刷新。

### Known Issues
- VMware 控制台的鼠标指针目前显示为小圆点，未呈现服务器发来的真实指针形状。
- 部分 Linux 客户机（如 Ubuntu 文本模式）在内核 / GRUB 阶段分辨率仍偏低，需要在客户机内调整，客户端无法改变。
- 虚拟化的来源编辑与快照对话框在真实应用里没有逐一走查；布局由自动化测试（含小屏滚动与明暗主题）覆盖。
- 连接工作台空状态的「重置」「浏览所有设备」等操作由单元测试覆盖，实机只检查了首次使用页（浅色与深色最小窗口）的显示。
- macOS 端未构建、未验证；产物未签名。
