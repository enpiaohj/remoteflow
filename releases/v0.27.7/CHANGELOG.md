## [0.27.7] — 2026-10-28

连接工作台列表分页。
本版本仅发布 Windows（win-x64）；未含 macOS 产物。

### Added
- 连接工作台：连接多了不再出现滚动条，列表底部新增分页条——「总计 N 项」、上一页 / 页码 / 下一页、每页条数下拉。
  每页条数可选 10 / 20（默认）/ 50 / 100 / 全部；页码超过 7 页时折叠为 `1 … 14 15 16 … 30`。
- 搜索、筛选、分组或排序变化时回到第 1 页，收藏 / 编辑 / 探测状态刷新则停留在当前页；新建、编辑、移动连接后若选中项在别的页，自动翻到它所在的页；
  删除后当前页越界回退到最后一页。「全选当前列表」与批量操作只作用于当前页；在线状态探测仍覆盖筛选结果的全部。

### Changed
- 分页逻辑在共享的 `ConnectionsPageViewModel`（`PageSize` 默认 0 = 不分页），只有 Windows 工作台页在打开时设为 20，macOS 端行为不变。
- README 截图按 v0.27.7 重拍（列表底部出现分页条）。

### Known Issues
- 每页 20 条时，窗口较矮会出现列表滚动条，可改成 10 条或拉高窗口。
- 首页「最近活动」把已连接的主机标为「失败」、历史里显示「无错误。」，尚未排查。
- 「最近连接」视图没有批量选择开关；macOS 端未构建、未验证；产物未签名。
