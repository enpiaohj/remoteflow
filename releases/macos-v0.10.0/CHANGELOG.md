# RemoteFlow macOS v0.10.0

发布日期：2026-09-28 · 上一版本 macos-v0.9.0

连接工作台整体对齐 Windows 版四栏结构，会话标签并入公共标题栏；补齐玻璃外观与
彩色身份图标；修复在线探测、凭据丢失提示与若干布局缺陷。改动集中在
`RemoteFlow.App.Mac`；“凭据丢失检测”一项落在共享层，Windows 端同步生效。

## 新增

- **连接工作台四栏布局**，对齐 Windows 版：纯图标导航栏 → 连接资源栏（智能视图 +
  分组，含数量徽章）→ 高密度多列主机表格 → 常驻详情栏。
- **连接列表改为真实多列表格**：名称 / 主机 / 协议 / 标签 / 在线 / 最近连接 / 收藏 /
  更多操作，协议与在线状态用彩色胶囊，在线离线一眼可辨；行尾 `⋯` 与右键菜单共用同一套操作。
- **设备类型矢量图标**：新增 `DeviceIconCatalog`，按设备类型（Windows PC / Linux /
  文件服务器 / 域控 / 虚拟化 / 数据库 / 容器等）渲染多色图标，取代原先按协议推断的单色图标。
- **玻璃外观**：设置页新增「窗口材质」（亚克力 / 云母 / 纯色）与「透明度」，
  切换实时生效；`Palette` 按材质与透明度计算底衬 alpha。
- **彩色身份图标**：把 Windows 版 25 个原创矢量图标转成 macOS 资源，接入凭据列表
  5 种类型、设置页 3 个分区与首页「收藏 / 最近活动」。
- 详情栏新增 **Ping / 测试连通性** 与 **更多操作** 按钮。

## 改进

- **会话标签移入公共标题栏**：标签作为标题栏工具栏的一项，紧随「会话」按钮，
  与窗口控件、搜索框同处一行（原先用标题栏附件实现，会在标题栏下方另撑出一整行）。
- **会话标签样式对齐 Windows**：协议图标 + 标题左对齐 + 连接状态点（绿=已连接 /
  橙=连接中）+ 常驻关闭叉；宽度按标题长短自适应，选中项为贴内容区的圆角卡片。
- **详情栏默认宽度 520 → 420**，列表栏拿回横向空间；实测详情内容无截断。
- 窗口底部新增状态栏（会话数 · 在线统计 · 凭据保护方式）。
- 「最近连接」列宽 82 → 96，修复同样 11 字符的时间戳有的完整、有的被截断的问题。

## 修复

- **会话画面不再从详情页开始**：点「连接」即在会话舞台显示连接中画面，并收起资源栏
  与列表栏，只保留图标栏（原先停在详情页显示「正在连接」，连上后才突然切换）。
- **在线探测超时项不再永久停在「探测中」**：macOS 端漏注册 `PresenceProbeService`；
  且列表刷新只重载第 0 列而状态在第 4 列，探测结果写回后界面不更新。
  另加硬超时与批次收尾兜底，避免 DNS 阶段不响应取消令牌导致状态不落定。
- **切换页面时列表栏「由窄跳宽」**：各栏宽度原先用 `SetPositionOfDivider` 设置，
  在 `NSSplitViewController` 的约束体系下会被下一轮布局覆盖，只能靠下一轮 runloop
  再纠正一次，而那次纠正发生在画面渲染之后。改用 Auto Layout 约束表达。
- **会话铺满时点当前页图标无反应**：导航项未变化时被去重逻辑吞掉，导致会话进行中
  点「我的连接」回不到工作台。
- **凭据密钥丢失给出准确提示**：钥匙串条目被手动删除后，原先会带着空密码去连接、
  把问题表现成「认证失败」，误导排查方向。现在检测到「记录声明有引用但取不到 Secret」
  即快速失败，提示重新填写凭据。
- 会话标签条不再铺不透明底色，避免在云母 / 亚克力材质下把标题栏玻璃切出一块死矩形。

## 构建

- **支持固定代码签名身份**（`csproj.user` / `RF_CODESIGN_KEY` 环境变量）。
  ad-hoc 签名的 designated requirement 含 cdhash，每次重新编译都会变，钥匙串 ACL 的
  「始终允许」随即作废，表现为每次重跑逐条弹系统密码框。固定证书后签名身份跨构建稳定。
- 修正 `SecurityFramework` 中一处与 API 行为相反的注释：`SecAccessCreate` 的
  `trustedlist = NULL` 是「只信任创建者」而非「放开所有应用」，方法相应更名。

## 内部

- **重写 Git 历史清除已发布的敏感内容**：早期快照脚本仅排除 `releases/`，把 `docs/`
  （内部产品设计 / 提示词 / 测试文档）、`.github/` 与 `CLAUDE.md` 一并打进公开源码快照，
  其中含内网 IP、内部主机名前缀与内部项目代号。已用 `git filter-repo` 从全部历史移除
  上述目录并替换内网地址为文档专用网段（RFC 5737），同时修改快照脚本堵住来源。
  重写前已用 `git bundle` 全量备份并校验；55 个 tag 全部重建，11 个 GitHub Release
  及其产物核对无误。
