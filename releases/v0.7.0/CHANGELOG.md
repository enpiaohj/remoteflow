# RemoteFlow v0.7.0

发布日期：2026-09-06

上一正式版本为 v0.6.0。本版完成一轮协议功能增强与 RDP 高级设置最终收口、托盘右键结构化菜单。

> **待真机确认（自动化均已覆盖 Release 0/0、Core 42 / Integration 85）**：
> - RDP：分辨率预设/自定义、启动全屏与多显示器联动、麦克风（RDP8 音频捕获）、连接质量映射的实际 ActiveX 行为。
> - SSH：终端主题观感、全屏下搜索浮层 Esc 交互、bracketed-paste 粘贴语义。
> - VNC：远端复制 → 本机剪贴板接收。
> - 托盘菜单交互与「断开全部会话」；Session 生命周期/实时状态压测 runbook。

## Added（协议与编辑）

- **编辑连接 RDP 高级收口**：显示/本地资源/连接与安全/体验 四个轻量 Section，视觉与外部编辑表单同底色（去嵌套灰卡），Focus 用轻量蓝色圆角环、鼠标不显系统虚线，底部 取消/保存/保存并连接 固定。
- **显示模式与分辨率互斥联动**：适应窗口（默认，随 Session 自适应）与固定分辨率互斥；固定时启用分辨率（1280×720/1366×768/1600×900/1920×1080/2560×1440/自定义，自定义 1–16384 校验并回填）。
- **多显示器 ↔ 启动全屏联动**：勾选「使用全部显示器」自动启用「启动后进入全屏」并提示依赖；F11 应用全屏逻辑不变。
- **本地资源新增「麦克风重定向」**：真实映射 `AudioCaptureRedirectionMode`（需 RDP 音频捕获/本机支持），勾选时自动连带「音频播放到本机」。
- **体验新增「连接质量」**：自动/局域网/高速网络/低带宽网络，映射 `NetworkConnectionType`；不暴露逐位体验参数（避免假开关）。
- SSH / VNC「高级设置」视觉与 RDP 统一去卡片化（层级一致，字段结构不变）。

## Added（SSH 终端体验）

- 终端主题：内置 Dark Gray / Black / Navy / Solarized Dark / Light + 跟随应用（完整 palette：前景/背景/光标/选区 + ANSI 16），会话按设置应用并随应用深浅联动。
- 设置 → SSH：新增「终端主题」选择与轻量实时预览（背景/前景/ANSI chip + 字体字号）。
- 粘贴安全：多行粘贴确认、大文本（>4096）警告（独立开关），确认后经 xterm `paste` 发送以保留 bracketed-paste 语义。
- 会话内操作：清屏、搜索终端输出（引入与 xterm 5.5.0 匹配的 addon-search@0.16.0，页面内搜索浮层）。

## Added（其它）

- 会话 Tab 右键新增「关闭右侧会话」。
- 设置页 RDP/SSH 默认卡按 Section 组织；SSH 默认值补齐编码与粘贴安全字段。
- VNC：剪贴板「远端 → 本机」接收同步（IOutputHandler 挂载、marshal 写本机剪贴板；仅接收、不做假发送；存量连接默认关闭，新建连接默认开启）。
- **托盘右键结构化菜单**：打开/隐藏（单击显隐去抖、双击强前台）；新建连接（RDP/SSH/VNC 预选协议）；最近连接（≤5 + 查看全部）；活动会话（N）+ 断开全部（确认 → 标准 Session 清理）；设置；开机启动（双向同步设置）；正式退出（走 App 关闭清理，非强杀）。状态全部来自 SessionManager，菜单动态刷新，最近连接读库移出 UI 线程。

## Fixed

- RDP 高级设置此前存在“适应窗口”与“自动随窗口”语义冲突；现为互斥两态。
- 会话/连接名称含 `&` 时托盘菜单显示错乱（转义助记符）。
- 托盘「断开全部会话」确认前误把隐藏主窗口弹回前台（改为确认成功后置前）。
