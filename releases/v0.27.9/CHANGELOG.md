## [0.27.9] — 2026-10-28

针对 Windows Server 2012 R2 等较老系统的兼容修复，并新增 RDP 连接超时与日志级别设置。
本版本仅发布 Windows（win-x64）；未含 macOS 产物。

### Added
- 设置 → RDP → 连接 →「连接超时（秒）」：默认 120，与系统自带的远程桌面连接（mstsc）一致，范围 10–600，改动对新开的连接生效。
- 设置 → 数据与备份 →「日志级别」：信息（默认）/ 调试，切换立即生效、无需重启；日志仍不含密码与密钥。
- RDP 连接前增加 10 秒 TCP 预检：主机解析不了、端口拒绝、网络不可达或超时时立即给出明确的中文报错，不必等控件超时。
- RDP 连接过程的关键日志提到信息级别并带用时：开始连接、传输层已连接、登录完成、断开原因码与扩展原因码；
  控件不支持某个属性时也记录，便于排查老系统上的连接问题。

### Fixed
- RDP 连接超时写死 30 秒：域控制器、带「登录消息」对话框等登录较慢的服务器会被控件以
  「两台计算机无法在分配的时间内连接」（原因码 264）掐断，而 mstsc 连同一台没问题。默认改为 120 秒并可在设置里调整。
- 在 Windows Server 2012 R2 / Windows 8.1 及更早系统上，标题栏最小化 / 最大化 / 关闭按钮、会话工具条按钮、
  会话折叠后的下拉箭头、资源树与设置页的展开箭头、下拉框与子菜单箭头、复选框的勾显示为方块：
  这些图标原先依赖 Windows 10/11 自带的 Segoe 图标字体，现全部改为内置矢量图标（`WindowIcons.xaml`），不再依赖系统字体。
- Windows 8.1 / Server 2012 R2 上会话折叠后的下拉列表无法用鼠标滚轮滚动：这些系统把滚轮交给有键盘焦点的窗口（会话里是远程桌面控件），
  下拉列表收不到；现在列表打开时在消息循环里先一步截获滚轮并滚动列表，各系统行为一致。
- 连接中调用「断开」时部分控件版本返回 E_FAIL，此前每次都记成告警，现降为调试级别，不再刷屏。

### Known Issues
- 白屏的根因：2012 R2 上此前所有 RDP 目标都出现白屏，超时只解释了域控制器「过一会失败」；新版日志已能看到卡在握手的哪一阶段，
  如仍有白屏请带着调试级别日志反馈。
- 图标与滚轮修复在 Windows 11 上验证了渲染与逻辑，Server 2012 R2 上的实际效果以用户实测为准，发布时尚未收到确认。
- 会话工具条上的会话切换菜单条目很多时，在 2012 R2 上滚轮可能同样失效（本版本只修了折叠后的下拉列表）。
- 首页「最近活动」把已连接的主机标为「失败」、历史里显示「无错误。」，尚未排查。
- 「最近连接」视图没有批量选择开关；macOS 端未构建、未验证；产物未签名。
- `DpapiCredentialVaultTests.并发写入多个Secret互不覆盖` 在整套测试一起运行时偶发失败（单独运行稳定通过），原因未查。
