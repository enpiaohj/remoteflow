# RemoteFlow v0.22.0

发布日期：2026-09-27 · 上一版本 v0.21.0


玻璃外观：主窗口与对话框改用 Windows 11 系统材质（亚克力 / 云母），面板半透明，
并可在设置中切换材质、调节透明度。本版本仅封版 Windows（win-x64）；macOS 未改动、未含产物。
详细说明见 `docs/2026-09-27-RemoteFlow-v0.22.0-玻璃外观说明-v1.0.md`。

### 新增
- **窗口材质（设置 → 常规 → 外观与行为）**：亚克力（默认，模糊透出窗口后方内容）/ 云母（随桌面壁纸淡淡透色）/
  纯色（与以前完全一致）。切换即时生效。需要 Windows 11 22H2（build 22621）及以上，更低版本自动保持纯色；
  关闭系统透明效果、节能模式等场景由系统显示为纯色。
- **透明度滑块**：0–100%（步进 5，默认 50），拖动实时预览，仅在亚克力 / 云母下可用。只调节窗口底、
  工作区面板、卡片三层；菜单 / 下拉 / 提示保持近乎不透明，最透明时也保留一层薄涂保证文字可读。
- **对话框与浮层使用亚克力**：连接 / 凭据 / 分组 / 标签编辑器、主机密钥、测试连接、消息、口令、
  标签管理、连接质量浮层共 12 个窗口，玻璃外观下改为系统绘制的亚克力、圆角与阴影。
- 新增 Fluent 风格滑块样式。

### 变更
- 玻璃外观下文字配色：浅色二 / 三级文字各加深一档，深色三级文字提亮一档（亚克力背后内容过亮 / 过暗时
  实测最坏对比度：浅色三级文字约 3.2:1、正文 10:1 以上；深色 5.4:1 以上）。
- 新增背景语义键 `Bg.Chrome`（标题栏 / 状态栏 / 连接资源列）、`Bg.Workspace`（中央工作区 / 详情面板）、
  `Bg.Popup`（菜单 / 下拉 / 提示 / 浮层），纯色主题下与卡片同色，外观不变。
- 主题字典改用组件 pack URI 加载（不依赖入口程序集）。
- 设置新增 `WindowMaterial`（默认亚克力）与 `WindowTransparency`（默认 50）；旧设置文件升级后即为玻璃外观，
  可在设置中改回纯色。

### 修复
- 扩展系统边框后，系统标题按钮叠在自绘最小化 / 最大化 / 关闭按钮下方（移除系统菜单样式；标题栏右键系统菜单与
  Alt+F4 实测仍可用）；退出无边框全屏后重新套用材质，避免按钮再次出现。

### 已知问题
- 会话画面（RDP / SSH 终端 / VNC）为内嵌原生窗口，始终不透明（技术限制）。
- 页面切换后新页面内容不在 UI 自动化（辅助功能）树中，屏幕阅读器可能读不到（既有问题，非本版引入）。
- 会话完全全屏的进入 / 退出未在玻璃外观下做自动化验证。
- macOS 无玻璃外观设置（未改动）。
