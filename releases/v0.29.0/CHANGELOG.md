## [0.29.0] — 2026-11-03

会话体验增强：每次连接输入凭据（可记住）、标签与导航改进、关闭确认、恢复上次会话。
本版本仅发布 Windows（win-x64）；未含 macOS 产物。

### Added
- **每次连接输入凭据**：连接没分配凭据时，每次连接弹出「输入你的凭据」（版式与文案参照 Windows 安全中心 / mstsc），输入用户名和密码；
  凭据只保存了账户名时，账户名固定显示，只输入密码。密码只用于本次连接。
  - 勾选「记住我的凭据」：未分配凭据时新建一条凭据并分配给该连接（默认名称为用户名全称，如 `域\用户`），只有账户名时把密码补存进该凭据。
  - 「更多选项」：可直接选用已保存的凭据；勾选记住时可设置凭据类型与名称。
  - 凭据输入框仅 Windows 提供，macOS 行为不变。
- **会话标签显示方式**（设置 → 常规 → 会话）：自动折叠（标题栏放不下时收为下拉列表）或横向滚动（左侧箭头 + 鼠标滚轮，类似 Excel 工作表标签）。
- **返回会话**：从会话切到页面（如新建凭据）后，左侧导航栏底部与标题栏右侧出现「返回 会话名」，一键回到离开前的会话。
- **标题栏「+」**：紧挨窗口按钮，新建连接、凭据、分组、添加 ESXi / vCenter 来源。
- **连接编辑器**：凭据下拉第一行「＋ 新建凭据…」，建好后自动选中。
- **恢复上次会话**：退出时记住仍开着的会话（只记连接 Id，不含密码），下次启动询问是否重新打开；设置里可关闭。
- **全屏悬浮工具条初始位置**（设置 → 常规）：靠左 / 居中 / 靠右。
- **关闭当前会话前确认**（设置里可关）：只对正在查看且仍连着的会话提示，关闭其他标签、批量关闭、已断开的会话不提示。

### Changed
- 当前会话标签用品牌色淡底、描边和文字突出，其余标签文字变灰。
- 会话标签折叠改为只看标题栏宽度，不再「满 5 个就强制折叠」。
- 折叠态选择器的头部图标改用设备图标，与页面图标区分。

### Known Issues
- 「横向滚动」模式、设置页新增的「会话」卡片、全屏工具条左 / 右位置、凭据下拉展开时从第一行显示、恢复上次会话等，以自动化测试覆盖为主，未逐项实机走查。
- 崩溃或被强制结束时不会记住会话列表（只在确认退出时保存）。
- 批量连接多台没分配凭据的主机时，每台都会弹一次凭据输入框。
- `DpapiCredentialVaultTests.并发写入多个Secret互不覆盖` 整套测试一起运行时偶发失败（单独运行稳定通过），原因未查。
- macOS 端未构建、未验证；产物未签名。
