## [0.27.11] — 2026-10-28

连接工作台多选改进与分页条显示范围修正。
本版本仅发布 Windows（win-x64）；未含 macOS 产物。

### Added
- 连接列表支持资源管理器式多选：**Ctrl+单击**切换该行勾选；**Shift+单击**从起点连选到该行（替换原有勾选，范围含两端、可跨页）；
  **Ctrl+Shift+单击**连选并追加；**Ctrl+A** 全选当前列表；**Shift+↑/↓** 逐行连选（加 Ctrl 为追加）。

### Fixed
- 翻页后已勾选的项被清空：清理勾选集合时按「当前页」判断，翻到别页就把原来那页的勾选全移除了；
  现在按「筛选结果」判断，翻页不丢勾选，搜索 / 筛选把某项过滤掉时才会被移出；清除勾选与进出多选模式也会把其它页已勾选项的标记一并复位。
- 状态栏分页条在会话模式下仍然显示：现在只在连接工作台页显示，选中会话 Tab 时隐藏。
- 多选勾选时，行内的收藏 / 编辑 / 传输 / 更多按钮被行单击拦截：现在按钮自己响应点击。

### Changed
- 「全选当前列表」（表头勾选框、右键菜单、Ctrl+A）现在针对筛选结果的所有页，不再只是当前页；表头勾选框的全选状态也按所有页判断。

### Known Issues
- 2012 R2 上图标与滚轮修复的实际效果（v0.27.9 引入）仍以用户实测为准；白屏根因未完全确认，如有请附调试级别日志反馈。
- 会话工具条上的会话切换菜单条目很多时，在 2012 R2 上滚轮可能同样失效。
- 窗口很窄时，加宽后的会话选择器与右侧会话工具条会更挤，收缩规则未调整。
- 首页「最近活动」把已连接的主机标为「失败」、历史里显示「无错误。」，尚未排查。
- 「最近连接」视图没有批量选择开关；macOS 端未构建、未验证；产物未签名。
- `DpapiCredentialVaultTests.并发写入多个Secret互不覆盖` 在整套测试一起运行时偶发失败（单独运行稳定通过），原因未查。
