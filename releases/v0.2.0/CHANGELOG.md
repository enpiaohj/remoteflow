# RemoteFlow v0.2.0

发布日期：2026-09-04

本版本以「连接分组管理」「最近连接与历史」为核心新增功能，并对全应用视觉
体系做了一轮系统性重做（调色板、圆角/字号阶梯、图标规格、动效），同时修复
若干真实体验问题（会话全屏露边框、跟随系统主题后台不同步、窗口放大后内容
不自适应等）。上一个正式版本为 v0.1.1。

## Added

- **连接分组模型**：`GroupService` + 系统「未分组」+ 默认「我的设备」分组；
  「我的连接」改为嵌套分组树，支持展开状态记忆、右键 CRUD、拖动/菜单移动
  连接到分组；首次使用与空分组场景有专门的引导提示。
- **「最近连接」独立页面**：连接详情新增历史连接图表，列表页支持页内筛选
  （协议、状态、时间范围等）。
- **导航与设置重构**：左侧导航按功能分组；设置页改为标签式布局，
  「导入 / 导出」并入「数据与备份」标签；「常规」标签按分区重新组织，
  新增「默认进入页面」「界面语言」选项。
- **首页 / 凭据页 / 连接页视觉重做**：首页最近连接 Hero 卡片、收藏与最近
  活动双列列表、安全提示条；凭据页改为搜索 + 圆形头像 + 类型徽章 + 卡片式
  表格；连接列表统一图标 / 徽章 / 分组树的视觉语言。
- **底部细状态栏**：显示当前会话状态与「本地优先 · 凭据由 Windows DPAPI
  保护」提示，替代原来占用侧栏空间的写法。

## Changed

- **全局视觉体系重做**：统一冷中性调色板、圆角与字号阶梯、`Surface.Card`
  淡投影层次；导航项与按钮加入短促的悬停 / 聚焦淡入动效。
- **浅色主题改用 Windows 11 原生配色思路**：内容工作区背景改回白色
  （`Bg.Layer`），机身（标题栏 / 侧栏 / 状态栏）保留浅灰 `Bg.Base`，
  两者以「整窗同一底色，具体卡片才是白的」这一原生 Win11 应用惯例为准，
  不再是「一整块纯白 vs 周围灰」的强对比版式。
- **协议图标统一为容器样式**：连接列表 / 详情面板标题 / 凭据头像 /
  首页收藏与最近活动行的协议图标统一为 `IconTile.Background` +
  `IconTile.Glyph`（44px 圆角色块 + 12% 透明度协议色背景），列表图标
  尺度与详情面板对齐，不再有明显偏小的情况；首页「最近连接」大卡片
  图标进一步放大（64px）以突出快捷入口。
- **首页版式**：内容横向全宽铺满至页边距，纵向随窗口高度自适应
  （收藏 / 最近活动两张卡片撑满剩余空间、内部各自滚动，页脚按钮钉底）；
  默认窗口尺寸由 1440×820 增大到 1560×940。
- **全屏悬浮工具条**：造型打磨后仍保留原有「贴边、顶平底圆」的胶囊形态，
  内部按钮尺寸与整体比例做了统一。

## Fixed

- 会话进入全屏后，中央内容区原本常驻的描边与圆角未随之收起，导致远程
  画面四周露出一圈边框。
- 首页问候语在出现滚动条时会被顶出可视区（外层 `ScrollViewer` 与
  `MinHeight` 绑定互相干扰）。
- 跟随系统主题在应用处于后台时切换深浅色不同步（`SystemEvents` 只监听了
  部分 `UserPreferenceChanged` 分类）。
- 首页 / 连接页 / 设置页窗口放大后内容不随之铺满，仍保持初始尺寸的留白。
- 「我的连接」协议筛选下拉默认值显示异常，改用 `ProtocolFilterOption`
  枚举并默认显示「全部协议」。
- 凭据表格「名称」列原来按 `*` 撑满，把其余列挤到窗口最右侧、中间留出
  大片空白；改为按内容伸缩并封顶宽度，其余列紧跟其后左对齐排列。

## Known Issues

- VNC 协议图标字形（Icons.xaml 的 Icon.Vnc，码点 U+E7F8）尚未有真实 VNC 连接场景做过视觉验证，
  渲染效果留待下一次实机连接时确认。
- 本版本改动集中在 UI/UX 与连接分组管理，未涉及 RDP/SSH/VNC 协议层
  本身，未做额外的协议端到端回归（沿用既有测试覆盖）。
