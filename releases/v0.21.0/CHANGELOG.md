# RemoteFlow v0.21.0

发布日期：2026-09-27 · 上一版本 v0.20.0


正式图标体系与状态刷新：设备类型 / 协议 / 状态 / 分组 / 标签五类图标统一，
「我的设备」「未分组」改为永久内置分组，页面切换统一刷新（首页在线状态不再停留在「—」），
并启用全新程序图标「端点连接流」。本版本仅发布 Windows（win-x64）；
macOS 侧代码已同步适配，但未在 Mac 上编译与运行验证，未含 macOS 产物。
详细说明见 `docs/2026-09-27-RemoteFlow-v0.21.0-分组标签图标与状态刷新说明-v1.0.md`。

### 新增
- **设备类型与 12 种正式设备图标**：连接新增「设备类型」（Windows 电脑 / Windows 服务器 /
  Linux 服务器 / 域控 / 文件服务器 / macOS 设备 / Web / 应用主机 / 数据库服务器 / 网络设备 /
  虚拟机 / 容器 / 云主机），与协议正交；在连接编辑器中选择，列表、详情、首页、最近活动统一显示
  对应的多色矢量图标。未指定时按协议推断（RDP → Windows、SSH → Linux、VNC → macOS），
  存量连接升级后显示不变。
- **协议徽章**：RDP 蓝 / SSH 绿 / VNC 紫，协议色图标 + 缩写，全应用共用一个组件。
- **统一连接状态指示**：在线（绿）/ 已连接（蓝）/ 连接中与自动重连（琥珀）/ 异常（红）/
  离线（灰），列表、详情、首页、会话标签、状态栏同一语义。
- **连接资源智能视图图标**：所有设备 / 收藏 / 最近连接各有独立图标。
- **分组图标**：自定义分组可从 12 种组织图标中选择（文件夹、公司、数据中心、服务器机架、
  云环境、网络、数据库、Web 服务、安全、开发、实验室、归档）；右键「编辑分组」一次修改名称与图标，
  带实时预览。分组图标随云同步。
- **标签图标 + 颜色**：标签可选 10 种图标（标签、生产、测试、重要、安全、位置、项目、团队、
  网络、维护）并保留自定义颜色；标签管理、连接编辑器、列表、详情、标签筛选下拉统一显示。
  标签图标随云同步。
- **会话标签显示主机设备图标**：同类会话多开时按设备形状区分；协议与状态移入悬停提示
  （「名称 · 协议 · 状态」）。紧凑模式的会话选择器、测试连接对话框同步改用设备图标。
- **紧凑会话选择器**：会话数达到 5 个或标题栏放不下时，Tab 条切换为「当前会话」下拉，
  支持键盘（↑ / ↓ / Enter / Delete / Esc）与共享右键菜单。
- **会话标签右键菜单**：重新连接 / 关闭会话 / 关闭其他会话 / 关闭右侧会话 / 关闭全部会话。
- **详情面板动作分层**：主按钮随会话状态显示「连接 / 打开会话」，旁边下拉提供新建会话、
  重新连接、断开连接；低频动作（复制 IP、收藏、复制连接）收入「更多」。
- **首页在线探测**：最近连接与收藏卡片按主机做 TCP 在线探测（并发 8、单次 1.5 秒超时），
  同一设备同时出现在两个区只探测一次。
- **全新程序图标「端点连接流」**：两个设备端点由青蓝流线与向前箭头贯通；Windows 与 macOS
  共用同一套图形，16 / 24 / 32 px 使用单独简化字形。新增 `scripts/build-appicon.py`
  一次生成 Windows `.ico`（7 帧）、Logo PNG 与 macOS iconset / `.icns` 并自校验；
  `scripts/build-appicon.sh` 改为转调该脚本，旧 SVG 源文件移除。关于页、设置页品牌区
  同步使用新图标。

### 变更
- **「我的设备」「未分组」改为永久内置分组**：名称、图标、位置与默认身份固定，不能编辑、
  删除、移动或替换；仍可在其中增删连接，「我的设备」可建子分组，「未分组」不能建子分组。
  移除「设为默认分组」菜单、设置页「保护默认分组」开关与「删除默认分组后重选」流程（Windows 与 macOS）。
- **升级时自动校正内置分组**：沿用既有默认组的 Id（连接与子分组引用不迁移）；多台设备各自
  建立过的根级同名「我的设备」经云同步汇合后，按 Id 确定性选出唯一内置组，其余同名组的
  连接与子分组并入内置组（子分组重名时追加序号），再删除空的重复组——不删除任何连接。
- **云同步分组 / 标签 Schema 升级到 v2**：旧版 payload 兼容；远端不能修改或删除内置分组；
  不再仅凭名称把普通分组提升为内置组（避免多设备间来回翻转）。
- **页面切换统一刷新**：左侧导航改由 `CurrentPage` 作为唯一入口，鼠标、键盘与 UI Automation
  都会加载页面数据；再次点击当前页也会刷新；快速连续切页时取消旧加载、丢弃过期结果。
  从会话标签切回工作区时做轻量刷新（不重新探测主机、不重建连接列表）。
- 会话状态色调整为与列表一致：连接中 / 重连中由蓝改琥珀，已连接由绿改蓝，已断开由琥珀改灰
  （断线状态层仍提示重连）；状态栏「已连接 N 个会话」圆点改蓝。
- 深色主题主按钮文字改为深色（`Text.OnAccent` = `#0E1433`），对比度由约 2.6:1 提升到约 6:1。
- 首页「收藏」行的协议徽章与在线状态由上下叠放改为同行固定宽度对齐；「最近活动」行直接
  显示连接名，失败 / 取消以语义色标签标出（原为图标角落小点）。
- 连接资源列：智能视图图标 20 → 18 px、行高 34 → 32；分组图标 15 → 16 px、行高 26 → 28；
  计数统一右对齐成一列，两区左边缘对齐。
- 连接列表多选：勾选框插在名称列内部，出现时不推动其它字段；批量操作栏替换列头显示，
  不再让列表整体下沉一行。凭据页多选改用与连接工作台一致的清单图标开关，去掉多选提示行。
- 凭据表格列宽统一（列头与数据逐列一致），操作列固定到最右；凭据页、设置页标题增加顶部留白。
- 数据库 Schema 升级到 v7（v6：`connections.device_type`；v7：`connection_groups.is_built_in`、
  `tags.icon`），均为加列迁移，存量数据不变。

### 修复
- **首页在线状态不刷新**：首页此前自建行对象、从不探测，切回首页时一直显示「—」。
- **左侧导航点击当前页无反应**：会话标签在前台时，点击已选中的导航项无法回到工作区并刷新。
- **会话状态变化引发重复探测**：停留首页时每次会话状态跳变都会重新探测全部卡片主机并闪回
  「探测中」；现复用上次探测结果。
- **右键菜单残留分隔线**：「我的设备」隐藏编辑 / 删除后底部出现两条分隔线；分隔线整理
  统一为 `ContextMenuSeparators.Normalize`（首尾与相邻重复的分隔线折叠），应用于分组、
  连接行、首页行三类右键菜单。
- 连接列表「在线」与「最近连接」两列贴在一起；「在线」列头与状态胶囊错位 4 px。
- 凭据表「保险库」列头与数据列宽不一致（92 / 132 px），导致「引用」「操作」列头错位约 45 px。
- 详情面板「主机」标签与值不对齐；详情页编辑 / 新建连接后凭据回落显示「未指定」；
  详情页无法向下滚动（连接历史的内层滚动区吞掉滚轮，改为最多 10 条、交给外层滚动）。
- 分组 / 标签编辑器切换图标时预览不更新。
- 在「未分组」下可以创建或移入子分组。
- 会话最大化 / 全屏档左侧图标栏收起后标题栏只剩产品名、缺少 LOGO；状态入口双击防抖改为
  500 ms（此前双击可能把主窗口最小化）；
  会话 Tab 溢出时的原生横向滚动条改为左右箭头 / 紧凑选择器。
- 测试工程 `CS0067` 警告（未使用的测试计时器事件）。
