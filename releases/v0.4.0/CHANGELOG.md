# RemoteFlow v0.4.0

发布日期：2026-09-05

上一正式版本为 v0.3.2。本版以「连接链路与批量操作」为主线，并完成一轮首页与
「我的连接」的成品 UI 精修：连接入口统一、多选批量、凭据批量与筛选、详情分区、
日期时间统一、图标全应用一致、导航键盘可达性。

## Added

- **统一开会话链路，首页收藏可连接**：首页「最近连接」卡片、收藏行、连接列表、
  右侧详情等所有入口都收敛到 `MainViewModel` 的统一漏斗；重复打开同一台设备只
  聚焦已有会话而不重复创建；连接创建中防连点；失败统一清理占位并提示。首页收藏
  行单击选中高亮、双击（或回车）发起连接。
- **「我的连接」多选批量操作**：进入多选后可对多台设备批量连接、批量收藏切换、
  移动到分组、添加/移除标签、批量删除；分组 Header 三态全选、表头勾选全选当前
  结果；批量操作栏为成熟桌面形态（未选项只提示、已选才出现操作、删除置右危险色）。
  多选是临时上下文：离开连接/凭据页或切到会话即自动退出并清空；多选时自动隐藏
  右侧详情面板。
- **凭据批量与筛选**：凭据列表支持类型筛选下拉、批量删除、批量更改凭据类型
  （口令类互转，SSH 私钥不参与，按引用连接协议做兼容性校验）。
- **右侧详情完善并分区**：展示连接状态（已连接/正在连接/失败/未连接）、端口、
  复制主机、创建时间/最近连接/上次时长/连接次数；顶部核心操作区（图标/名称/收藏/
  状态/连接/编辑）固定，下方按「连接信息 / 使用信息 / 连接活动」分区滚动，新增
  「查看全部历史」入口。
- **首页信息与密度**：标题下第三行常显「N 个连接 · M 个会话进行中」（0 会话也
  显示）；标题区垂直间距压缩；「最近连接」三张卡片高度收窄约 10px。
- **导航键盘可达性**：左侧导航自定义轻量蓝色圆角 FocusVisual——鼠标点击不再出现
  WPF 默认虚线框，键盘 Tab 聚焦仍显示 Focus Ring，可访问性保留。

## Changed

- **图标统一**：全应用含协议的设备行图标与首页「收藏 / 最近活动」行一致——44px
  彩色淡色底 Tile + 协议 Glyph + 协议色徽章；首页「最近连接」大卡片是唯一放大
  例外（64）。本轮曾一度只对高密度列表采用「去淡色底」方案，实机核对后按反馈
  统一回带底 Tile，避免列表与首页两套图标并存。
- **版本号位置**：从底部状态栏移到标题栏左上角品牌区，右下仅保留本地优先与
  DPAPI 保护说明。
- **日期时间统一**：首页/列表/详情/历史/迷你图 Tooltip 全部走统一格式化服务，
  跟随「设置 → 常规 → 日期与时间」的日期格式、12/24 小时、星期、周数开关。

## Fixed

- 「我的连接」进入即勾选「多选」导致崩溃（ToggleButton 误套 Button 样式，
  TargetType 不匹配）。
- 从连接/凭据页切走时自动退出多选失效（原挂在导航命令上，改挂页面切换本身）。
- 勾选行后批量动作空转（勾选框只改行 VM 的 IsSelected，未同步选择集合）。
- 凭据类型筛选下拉显示对象类型字符串，而非标签文字。
- 小分辨率下固定尺寸主窗口把标题栏顶出屏幕、无法拖动/还原——窗口自适应可视区，
  标题栏右键可调系统菜单。
- 「星期 / 周数」开关只在本次会话生效、重启即丢——变更未写回设置存储。
- 详情「连接次数」显示被最多 50 条历史列表截断，改用独立 `COUNT` 查询取真实累计。
- 迷你图悬停时间硬编码 `MM-dd HH:mm`，现跟随用户日期与 12/24 小时设置。
- 「查看全部历史」跳转后默认落在“今天”范围、看不到更早历史；现放开时间范围并
  保持当前连接选中。
