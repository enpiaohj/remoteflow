# RemoteFlow v0.32.0

发布日期：2026-11-27

远程桌面主机上新增 PowerShell 远程会话。
本版本仅发布 Windows（win-x64）；未含 macOS 产物。

### Added
- **PowerShell 远程会话**：在远程桌面主机上另开 PowerShell 会话（WinRM，HTTP 5985），沿用该连接的主机地址与凭据。入口在连接行与首页的右键菜单、远程桌面会话工具条（含全屏胶囊）。与同一主机的远程桌面会话相互独立，不进入「恢复上次会话」。
  - 由系统自带的 `powershell.exe` 执行；终端外观与 Windows 11 终端默认值一致（Campbell 黑底、Cascadia Mono、竖线光标），支持搜索与复制粘贴。
  - 一旦离开远程会话（`exit`、断线、连接失败）进程立即结束，不会回到本机命令行；账号密码经仅当前用户可访问的一次性管道传递；远程命令不写入本机 PowerShell 历史；关闭标签时同时关闭远端会话。
- **首次连接自动信任**：用 IP 或非域环境连接被 Windows 以「目标不受信任」拒绝时，应用经 Windows 管理员确认框把**这一个地址**追加到本机 TrustedHosts 后自动重连，每台电脑一次；从不写通配符，取消则不改动。注意该设置对本机所有用户生效，且列表中的主机不会被验证身份。连接本机时改走 `localhost`。
- **远程启用 PowerShell 远程**：会话因 WinRM 端口不通而失败时可用。先只读检查目标，确认后经 WMI 执行 `Enable-PSRemoting`，并报告结果与撤销方法；目标有「公用」网络时不做任何改动。目标的 135 端口（RPC）不通时直接说明无法远程启用——Windows 10 / 11 的默认防火墙通常如此。
- **会话标签类型标记**：标签、会话下拉列表与折叠头部在名字前显示 `RDP` / `SSH` / `VNC` / `PS`（虚拟机控制台为 `VM`），名字被截断时也能分清。

### Changed
- 连接失败的错误框改为不透明底色、内容可滚动，并可「复制全部」（不含账号密码）。PowerShell 的处理命令单独成块、可复制并附风险与撤销方法，系统原始报错默认折叠；本地账户被拒绝时说明 UAC 远程限制。
- 连接历史与日志区分 PowerShell 会话。

### Upgrade / Rollback
- 从 v0.31.0 升级：先正常退出旧版，再运行本版 EXE；ZIP 解压后包含同一份 EXE。凭据保险库与配置格式未变。连接历史表新增一个带默认值的列，**数据库版本号不变**；升级前的历史记录仍按远程桌面显示。
- 回退：正常退出本版，运行保留的 v0.31.0 EXE 即可打开同一份数据（新增的列会被忽略）。升级前仍建议在程序完全退出后备份 `%LOCALAPPDATA%\RemoteFlow`（使用 `REMOTEFLOW_DATA_DIR` 时备份对应目录）。本版自动加入的 TrustedHosts 条目属于 Windows 设置，回退后依然保留。

### Known Issues
- 远程启用的「执行启用」步骤尚未经应用在真实电脑上执行过（只读检查与认证失败在真实 Windows 10 上验证过，执行流程由测试覆盖）。
- PowerShell 会话暂不支持 WinRM over HTTPS，也不支持直接使用当前 Windows 身份登录；表格按连接那一刻的终端宽度排版，调整窗口后需重新连接。
- 保存凭据偶尔可能失败并报「无法删除要被替换的文件」（自动化测试中偶发，此前版本即存在，原因尚未查明）。这种失败下原有保险库文件保持不变，重试即可。
- 用 VNC 连接 macOS 时在内网千兆下仍感觉较慢，本版未做改动。
- 沿用此前版本：远程关机 / 重启未在真实远程设备执行；macOS 端未构建、未验证（本版改动了两端共享层）；Windows 产物未签名。
