# RemoteFlow v0.3.0

发布日期：2026-09-05

本版本新增标签的完整管理能力（此前标签只能勾选、无法创建或改色），
新增「帮助与关于」入口与常驻版本号显示，并修复两个真实存在的交互
bug：SSH 主机密钥信任弹窗会被残留按键瞬间关闭、标签颜色色板点击无
响应。上一个正式版本为 v0.2.0。

## Added

- **标签管理**：新建、编辑（改名 / 改描述 / 改颜色）、删除标签。
  连接编辑器的标签区新增「+ 管理标签」入口，始终显示（此前一个标签
  都没有时整行会隐藏，导致用户找不到入口）。标签编辑对话框提供
  10 色预设色板 + 自定义 `#RRGGBB` 输入，两者双向同步。
- **帮助与关于**：侧栏「管理」分组新增「帮助与关于」入口，弹出对话框
  展示应用信息、真实生效的快捷键速查（`Ctrl+K` 聚焦搜索、`Ctrl+N`
  新建连接、`Ctrl+W` 关闭当前会话、`F11`/`Esc` 全屏切换）与本地优先
  安全说明。
- **版本号常驻显示**：底部状态栏右侧常驻显示当前版本号，不再需要
  进入设置页才能查看。

## Fixed

- **SSH 主机密钥信任弹窗被残留按键瞬间关闭**：弹窗的「取消连接」按钮
  同时绑定了 `IsDefault` 与 `IsCancel`，弹窗刚打开时如果有残留的
  回车或 Esc 按键事件送达，会被立即当作「取消连接」处理，表现为
  弹窗一闪而过、无法正常确认信任。修复为窗口打开后 400ms 内整体
  禁用按钮，吸收残留输入后再允许交互。
- **标签颜色色板点击无响应**：色板用 `Border` 而非 `Button` 实现，
  点击事件会冒泡到窗口级的拖动处理逻辑并被其接管，导致色板永远
  收不到松开事件。改为在按下时直接处理选色并显式标记事件已处理。

## Changed

- 加固 SSH 主机密钥查询路径的线程假设，改用 `Task.Run` 隔离数据库
  查询，避免调用线程若非预期地带有 UI 同步上下文时产生死锁风险；
  同时补充了诊断日志（默认级别可见），便于下次复现时定位。

## Known Issues

- VNC 协议图标字形（`Icons.xaml` 的 `Icon.Vnc`，码点 U+E7F8）仍未有
  真实 VNC 连接场景做过视觉验证。
- SSH 主机密钥信任弹窗的修复未能在真实 Linux 主机上现场复现验证
  （本机无可用 sshd），基于用户描述与代码级根因定位完成，请在实机
  场景下留意确认。
