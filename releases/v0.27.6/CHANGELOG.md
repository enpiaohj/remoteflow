## [0.27.6] — 2026-10-28

修复应用内更新后快捷方式与开机启动项的善后。
本版本仅发布 Windows（win-x64）；未含 macOS 产物。

### Fixed
- 更新后快捷方式只改了目标、文件名仍带旧版本号（如开始菜单里的 `RemoteFlow-v0.27.3-win-x64.lnk` 指向 v0.27.5）：
  现在快捷方式若就叫旧 exe 的名字，改指向后一并改成新 exe 的名字；自己起名的快捷方式、已被占用的新名字、任务栏固定项不改名。
- 快捷方式显式指向旧 exe 的图标路径，现在随目标一起改到新 exe。
- 以前某次更新漏改的开机启动项（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的 `RemoteFlow`）与快捷方式，只要指向「同目录、发布产物命名、且已被删除」的旧版本，
  更新时与每次启动时（后台一次）都会改指向当前 exe，不再依赖更新当次留下的标记文件；目标已是新文件、名字还带旧版本号的快捷方式也在启动时补改名。

### Known Issues
- 名字含中文的快捷方式在非中文 ANSI 代码页的系统上，系统脚本接口保存不了，会被静默跳过；开始菜单「固定」磁贴存在系统私有数据库里，改不了；
  开机启动只处理 Run 注册表项与启动文件夹里的快捷方式，任务计划等其它方式不处理。
- 首页「最近活动」把已连接的主机标为「失败」、历史里显示「无错误。」，尚未排查。
- 「最近连接」视图没有批量选择开关；macOS 端未构建、未验证；产物未签名。
