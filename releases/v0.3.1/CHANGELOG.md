# RemoteFlow v0.3.1

发布日期：2026-09-05

本版本是针对 v0.3.0 遗留问题的补丁修复：SSH 主机密钥信任弹窗仍会在部分场景下
一闪而过导致连接失败。上一个正式版本为 v0.3.0。

## Fixed

- **SSH 主机密钥信任弹窗仍会被残留鼠标输入瞬间关闭**：v0.3.0 已经修复过一次
  「残留键盘输入（Enter/Esc）误关弹窗」的问题，但该弹窗作为无边框窗口，另外
  挂了一个用于支持拖动的 `MouseLeftButtonDown` 处理器，这个处理器直接绑在
  窗口本身、不受两个按钮的输入宽限期保护。残留或时序错位的鼠标按下事件
  （例如触发「连接」的那次点击）打到刚创建的弹窗上会调用 `DragMove()`，
  而该方法在鼠标左键未真正按住时会抛出异常；异常被应用级异常兜底记录后，
  弹窗所在的模态消息循环已经被打断，窗口随之瞬间关闭，`DialogResult` 从未
  被设为「已接受」——表现与用户主动点了「取消连接」完全一致。现已将拖动
  处理器纳入与两个按钮同一套 400ms 输入宽限期保护，并为 `DragMove()` 增加
  防御性异常处理。**已在实机连接真实 SSH 主机时验证，信任窗口能正常停留。**

## Changed

- SSH Host Key 确认框返回的诊断日志补充耗时统计，明显短于宽限期的返回可
  直接作为「弹窗被误关」而非「用户真实拒绝」的证据，便于未来快速定位同类问题。
