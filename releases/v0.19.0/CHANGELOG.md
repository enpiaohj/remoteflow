# RemoteFlow v0.19.0

发布日期：2026-09-26

连接工作台全面改版：资源树 + 扁平列表 + 常驻详情的三栏工作台、在线探测、批量操作
增强，并整体切换到「图标栏 + 纸张白 + 发丝线分区」的全新视觉（概念设计 v0.2）。
上一正式版本为 v0.18.1。

**本版本仅发布 Windows**；macOS 未改动、未发布（macOS 线最新为 `macos-v0.8.3`）。

设计文档：`docs/design/2026-09-26-连接工作台概念设计-v0.2.html`（概念稿，内含虚构演示数据）。

## Added

### 连接工作台（页面改版）

「我的连接」升级为工作台形态，页面重排为三栏：

| 区域 | 内容 |
| --- | --- |
| 左栏·连接资源（216px） | 智能视图（全部连接 / 收藏 / 最近连接，带全量计数）+ 分组树（子树计数、折叠状态持久化、分组右键菜单：新建连接 / 新建子分组 / 重命名 / 设为默认 / 删除） |
| 中栏 | 恒扁平列表（分组维度由左树承担，选中分组即过滤） |
| 右栏·详情（292px） | 选中连接的完整信息与操作（见下） |

- 左树选中分组 → 中央列表只显示该分组子树内连接；标题区出现分组章，可一键退出。
- 树始终反映全量数据（计数不受筛选影响），空分组保留；展开 / 折叠状态持久化。

### 在线探测

- `PresenceProbeService`：TCP 单步快探测（并发 8 / 超时 1.5s / 可取消），与
  「测试连接」（DNS → Ping → TCP 三步深度诊断）分工，后者保留不变。
- 列表新增「在线状态」列：已连接（存在活动会话，恒绿）/ 在线 / 探测中 / 离线
  （中性灰，不渲染为告警红）/ 未探测「—」；tooltip 标注探测时间。
- 进入工作台自动探测当前视图；工具条「探测」按钮手动重跑；重复触发自动取消上一批。
- 状态筛选下拉：全部 / 仅在线 / 仅离线（探测关闭时隐藏）。
- 设置 → 常规 →「连接工作台在线探测」开关（默认开）；关闭后状态列回「—」，仍可手动探测。

### 批量操作

- 勾选框与收藏星标独立成列常驻，勾选 ≥1 项即浮现批量栏（移动到分组 / 添加标签 /
  收藏切换 / 更多 / 删除）。
- 动作条「批量操作 ▾」菜单：全选当前列表 / 清空选择 / 批量连接 / 收藏切换 /
  移动到分组 / 添加标签 / 移除标签 / 删除所选。

### 详情面板增强

- 名称下方主机副标题（等宽字体）；「连接 ▾」下拉（测试连接 / 编辑）。
- 快捷动作宫格 2×3：编辑 / 复制 IP / Ping / 收藏切换；Traceroute 与打开 Web 为
  预留禁用位（后续版本）。
- 「连接信息 / 使用信息 / 最近活动」三分区可折叠（默认展开）；分组显示完整路径
  （如「生产环境 / Windows / 应用服务器」）；连接历史改时间线形态（圆点 + 连接线）。

### 搜索与筛选

- 页内搜索支持 **Ctrl+K** 聚焦（含键帽提示）；新增标签筛选、在线状态筛选下拉；
  排序下拉保留。

### 单元测试

- 新增 `PresenceProbeTests`（4 例）：本机监听端口在线 / 无监听端口离线 /
  批量取消不误报 / 行状态列展示映射。

## Changed

- **「我的连接」改名「连接工作台」**；工作区页签与会话标签上移至标题栏行且常驻
  （无会话 / 有会话统一，浏览器式）；完全全屏时仍随标题栏整行收起。
- **视觉切换概念设计 v0.2**：
  - 左导航降级为 **48px 模块图标栏**（logo 移入栏顶；首页 / 连接工作台 / 凭据 /
    设置 + 底部帮助 / 关于；收藏 / 最近连接降为工作台内的智能视图）。
  - 内容区统一**纸张白**（Bg.Layer）+ **发丝线分区**，去除卡片嵌套。
  - 顶部两层工具行：上下文条（标题 + 全量统计「N 台设备 · M 台在线」+ 探测 / 刷新 /
    批量操作 / 新建连接）+ 筛选条（搜索 + 协议 / 标签 / 状态 / 排序）。
  - 表格 44px 行高、行内设备图标 28 规格（44 规格保留给首页 / 详情）、最近连接列改
    超短日期（MM-dd HH:mm，新增 `DateTimeDisplay.ShortDateTime`）、行底发丝分隔线。
  - 标题栏不再放置全局搜索与「新建连接」按钮（页内承担；Ctrl+N、全局 Ctrl+K 重定向
    到工作台搜索框）。
- **窗口最大化 / 完全全屏档**：资源树随档位折叠（Border 与列宽联动），列表独占内容区。
- **凭据页**：列表行高 56→44、图标 44→28 规格、名称字号对齐，与工作台密度统一。
- 状态栏计数徽章改「在线 X / N」（探测关闭时「共 N 个连接」）。
- Core：`AppSettings` 新增 `PresenceProbeEnabled`（默认 true）；`PresenceProbeService`
  新服务（DI 注册）。

### 保持内置、未开放配置

进全屏初始 3 秒驻留、显示后 450ms 最短驻留、单击远端立即收起（会话药丸既有行为）、
探测并发数与超时、单击行仅选中 / 双击或 Enter 连接（既有交互约定）。

## Known Issues

- 在线探测 / 档位折叠依赖真实光标、会话与窗口状态，自动化测试无法覆盖；
  实机走查覆盖了启动、页面布局与「探测 → 在线/离线」链路，**窗口最大化档需开会话后
  F11 进入**，建议用户实机确认三档切换。
- macOS 侧未编译验证：本次共享层改动为纯加法（`AppSettings` 新属性 + 新服务 +
  新测试），`App.Mac` 未消费新 API，行为不受影响；下个 macOS 版本周期补编译确认。
- GitHub Actions 仍处弃用状态（2026-09-10 起，账户计费问题），本版本按规范本地门禁发布。
