# RemoteFlow v0.33.0

发布日期：2026-11-27

界面整体打磨：按一次完整的界面走查（47 台演示设备、浅色 / 深色、1024 / 1600 / 1920 宽）集中修复，并换上新的程序图标。
本版本仅发布 Windows（win-x64）；未含 macOS 产物。

### Changed
- **工作台表格按宽度自适应**：名称、状态、操作任何宽度都显示；变窄时依次收起标签、分组、最近连接、协议、地址，很窄时名称缩短。此前 1600 宽看不到状态与操作列。
- **工作台不再分页**，排序新增「状态」（在线在前），也可点「状态」列头排序。
- **远程桌面连接中**显示主机名、进度与「取消连接」。此前内容区是一整块白色（深色主题同样）。
- **连接失败提示更简洁**：默认只显示一两句结论，原因说明与处理命令收进「查看处理办法」，系统原始报错单独折叠。
- **会话标签精简**：只留类型标记、名称与关闭按钮，不再另放设备图标；状态圆点只在没连上时出现；关闭按钮只在当前标签或悬停时显示（保留占位，标签宽度不跳）。
- 会话工具条里地址与右侧按钮之间留出固定间距，「…」不再压到地址上；点击后不再残留虚线焦点框。
- **会话工具条精简**：远程桌面的缩放、Ctrl+Alt+Del、任务管理器、文件传输、PowerShell 收进带文字的「更多」菜单；SSH 只常驻文件传输，VNC 只常驻缩放。全屏悬浮胶囊未改动。
- 「连接 ▾」改为这台主机的其他打开方式（PowerShell / 文件传输），不再与下方按钮重复；详情「…」去掉与旁边按钮重复的复制地址、收藏，加入删除。详情标题可显示两行。
- 连接时的凭据输入框：用户名只显示一次并带「用户名：」标签。
- 状态栏按会话实际状态描述（如「8 个会话 · 1 个连接中 · 7 个已中断」），不再在开着会话时写「无活动会话」。
- 首页指标改为在线 / 离线 / 已连接会话，点在线或离线直接跳到工作台并带上筛选。
- 设置：RDP、VNC 改为与其他分页一致的「说明在左、开关在右」；「关于」卡片改为全宽；「数据与备份」两列卡片等高。
- 新建凭据先选类型；名称留空时按用户名（有域时为「域\用户」）生成。
- 凭据页删除按钮只在悬停或选中时出现，窄窗口下操作列不再被裁掉。
- 标题栏「+」在工作台与凭据页隐藏（页面上已有新建按钮），提示气泡不再遮住下方按钮。
- 对话框最大高度跟随屏幕可用区域，矮屏上底部按钮不会落到屏幕外。
- 文件服务器换成专用的存储柜图标（原先与分组的文件夹图标相同）；VNC 设备未设置类型时显示通用显示器，不再默认画苹果。
- 帮助页更新：「连接工作台」名称、五类凭据、PowerShell 会话与信任列表、类型标记。

### Added
- **新程序图标「立体双箭头」**：带厚度侧面、顶边高光与弧形反光的蓝 → 靛底座；白色挤出前箭头配淡青辉光，青蓝玻璃后箭头作流动回声，表达「连上、流动」。各尺寸都从矢量直接渲染，16 / 24 / 32 px 用单独加粗的简化字形；Windows 与 macOS 共用同一套图形。设计源改为 `scripts/appicon/*.xaml`，由 `scripts/render-appicon.ps1` 渲染、`scripts/build-appicon.py` 打包（生成图标现在需要在 Windows 上进行）。
- **设置 → 安全「PowerShell 信任的主机」**：查看本机 TrustedHosts，逐项移出（需 Windows 管理员确认）。

### Fixed
- **读屏软件可用**：图标按钮读出提示文字而不是图形数据；列表项读出设备名而不是类名；从左侧栏换页后新页面能被读屏识别（此前设置页整页读不到）。
- SSH 已连上端口但对方随即断开时，不再提示「无法连接到目标主机」，改为提示检查端口与 SSH 服务。

### Known Issues
- 远程桌面「连接中」改为先隐藏原生控件再显示，只在本机无输入的离线主机场景核对过界面；真实服务器的登录过程未实测。
- 全屏悬浮胶囊里的协议按钮仍是逐个图标。
- macOS 端：共享层的状态栏文案、排序与设备图标推断同步变化，未在 Mac 上构建与验证；通用显示器图标在 Mac 上没有对应图片，会回落到协议色块。
- 升级后资源管理器、任务栏或开始菜单可能暂时仍显示旧图标：这是 Windows 的图标缓存，重启资源管理器或等缓存刷新即可。
- 沿用 v0.32.0：保存凭据偶尔可能失败并报「无法删除要被替换的文件」（原因未查明，原保险库文件保持不变，重试即可）；远程启用的「执行启用」步骤未在真实电脑上执行过；PowerShell 暂不支持 HTTPS 与当前 Windows 身份；VNC 连 macOS 偏慢；Windows 产物未签名。

### Upgrade / Rollback
- 从 v0.32.0 升级：先正常退出旧版，再运行本版 EXE；ZIP 解压后包含同一份 EXE。数据库、凭据保险库与配置格式均未改动。工作台不再分页，原先选的「每页条数」不再生效。
- 回退：正常退出本版，运行保留的 v0.32.0 EXE 即可，数据照常可用。升级前仍建议在程序完全退出后备份 `%LOCALAPPDATA%\RemoteFlow`（使用 `REMOTEFLOW_DATA_DIR` 时备份对应目录）。
