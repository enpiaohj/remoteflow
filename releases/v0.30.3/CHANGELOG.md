# RemoteFlow v0.30.3

发布日期：2026-11-19

修复拖动标签后会话黑屏等问题，更新提示更醒目，恢复上次会话的对话框更易读。
本版本仅发布 Windows（win-x64）；未含 macOS 产物。

### Fixed
- 拖动或用菜单移动标签后会话画面黑屏：内容区的画面宿主和标题栏标签共用同一个集合，WPF 把换位当成「移除 + 新增」，会话画面（RDP / 终端 / VNC 的原生窗口）被销毁重建。现在内容区使用顺序固定的集合，换位不再重建画面。
- 标题栏标签无法拖动：按下标签时它自己持有的鼠标捕获被接管，丢失捕获的通知被误当成「拖动结束」。
- 标签拖到第一个位置不动、与页面标签视觉重叠：换位判断改为被拖标签的边缘对邻居中点，被拖标签比第一个标签宽时也能到位。

### Changed
- 更新提示：标题栏版本号旁由单个小图标改为品牌色胶囊按钮（「新版本 vX.Y.Z」/「下载中 N%」/「重启完成更新」），出现时发光脉动 3 次后静止；导航栏「设置」图标右上角加红点并在提示中说明；点击仍是原有菜单，「本次不再提示」同时隐藏按钮与红点。
- 恢复上次会话的对话框：会话一行一个并标注协议，最多列出 8 个，更多的显示「另有 N 个」；确认按钮改为「重新打开」。
- 拖动标签与折叠列表手柄时使用 Windows 标准的移动光标（四向箭头）。
- 标签拖动手感：被拖标签跟随鼠标并带抬起效果，邻居平滑让位，靠近边缘自动滚动，松手后平滑落位。

### Added
- 折叠会话列表每行新增拖动手柄，可上下拖动调整顺序；会话与文件传输标签的右键菜单新增「上移 / 下移」（标题栏标签为「左移 / 右移」）；折叠列表中选中某行后可用 Alt+↑ / Alt+↓ 移动。

### Upgrade / Rollback
- 从 v0.30.2 升级：先正常退出旧版，再运行本版 EXE；ZIP 解压后包含同一份 EXE。本版未修改 SQLite Schema、配置字段及凭据保险库格式。
- 回退：正常退出本版，运行保留的 v0.30.2 EXE；升级前建议在程序完全退出后备份 `%LOCALAPPDATA%\RemoteFlow`（使用 `REMOTEFLOW_DATA_DIR` 时备份对应目录）。

### Known Issues
- 拖动的跟手、动画、自动滚动、光标，以及更新胶囊按钮与设置红点在真实「有新版本」场景下的外观，依赖真实鼠标 / 真实发布，无自动化覆盖；换位规则、菜单可用状态、列表同步与按钮文字由测试覆盖。
- 沿用 v0.30.0：远程关机 / 重启未在真实远程设备执行；macOS 未构建、未验证；Windows 产物未签名。
