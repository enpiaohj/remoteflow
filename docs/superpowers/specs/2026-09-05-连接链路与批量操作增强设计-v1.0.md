# RemoteFlow 连接链路统一与批量操作增强 设计文档

文档版本：v1.0　日期：2026-09-05

## 1. 背景与目标

用户反馈三点，本文统一覆盖：

1. **首页收藏列表里的设备无法触发连接**——点击整行无反应，连接只能靠行尾 `⋯`
   菜单，交互不直观。
2. **单机（本地）连接机制需整体优化**——发起连接到真正开会话 Tab 的整条链路，
   包含同设备去重/聚焦、正在连接反馈、失败清理、多入口行为统一。
3. **一次功能增强：批量操作**——在「我的连接」页（含其全部 / 收藏 / 最近连接
   子视图）对多台设备批量连接、批量收藏切换、批量分组/标签、批量删除。

判定为 SemVer **MINOR**（批量为新功能 + 链路行为增强），版本从 v0.3.2 升 **v0.4.0**。

## 2. 现状（已核对代码）

- 发起连接的代码散落三处且逻辑重复：
  `HomePageViewModel.ConnectAsync`、`ConnectionsPageViewModel.ConnectAsync`、
  `MainViewModel.ReconnectAsync`。
- `SessionManager.CreateSessionAsync` 只受 `MaxConcurrentSessions`（默认 20）限制，
  **没有按 Profile 去重**——同一台设备双击两次会建两个会话、开两个 Tab。
- `SessionManager` 在 `CreateSessionAsync` 早期先 `await ResolveAsync(credential)`
  再登记进 `_sessions`，期间有并发窗口：连点会被建出重复会话。
- 列表行“进行中”态由 `ConnectionItemViewModel.HasActiveSession` 承担（首页最近卡
  用）。行主体（收藏行）不是按钮，双击/回车没有命中。
- 「我的连接」页列表 `SelectedItem` 单选，行首 36px 列是收藏星标；无多选基础。
  批量的四个子视图共享 `Items`（筛选后可见集）。

## 3. 方案总览

三块工作：

- **A 统一连接链路**：新增单一漏斗 `MainViewModel.OpenSessionAsync(Profile)`，
  所有入口统一；同设备去重/聚焦；创建中防连点占位；失败清理。
- **B 批量操作**：「我的连接」页显式「多选」模式 + 顶栏批量动作条，
  覆盖批量连接 / 收藏 / 分组 / 标签 / 删除。
- **C 首页收藏行可连接**：收藏行补双击连接，与「我的连接」列表手势一致。

## 4. 详细设计

### 4.1 A 统一连接链路

#### 4.1.1 单一漏斗

`MainViewModel` 新增：

```csharp
public async Task<OpenSessionOutcome> OpenSessionAsync(ConnectionProfile profile)
```

所有入口改为调用它（经事件/回调注入到各页面 VM，保持 UI→VM 依赖方向）：

- 首页「最近连接」卡（单击）。
- 首页「收藏」行（双击，见 4.3）。
- 我的连接行（双击/Enter）、行 `⋯`/右键「连接」。
- 收藏 / 最近连接子视图行（同一套列表）。
- 会话 Tab「重新连接」。

返回语义（供 UI 差异化提示，可选最小版返回 bool）：

| 情况 | 行为 |
| --- | --- |
| 已存在同 Profile 会话（连接中或已连） | 选中并聚焦其 Tab，不新建；轻提示「已在连接」 |
| 同 Profile 正在创建中（防连点窗口） | 忽略本次请求，聚焦正在创建的 Tab |
| 不存在 | `SessionManager.CreateSessionAsync` → `SessionCreated` → 新 Tab |

#### 4.1.2 SessionManager 侧：创建中占位 + 清理

- 内部维护 `ConcurrentDictionary<Guid /*profileId*/, ...>` 记录“创建中”状态，
  `CreateSessionAsync` 入口对同 Profile 已占位时返回 `null`（或抛专用结果），
  避免 `ResolveAsync` 期间连点重复建会话。
- `CreateSessionAsync` 抛异常（凭据缺失 / 达并发上限等）时，若已登记过占位须移除；
  占位随会话真正入 `_sessions` 或失败一起收敛。
- 若占位与 `_sessions` 冗余，可只以 `_sessions` 是否存在 + 一个轻量
  `in-flight` 集合表达。

#### 4.1.3 失败与清理

- 建立前失败：`OpenSessionAsync` 向上抛/返回标准化 `ConnectionException`，
  由各入口统一弹既有对话框文案（无法建立连接），不留空白 Tab。
- 建立后运行失败：沿用会话视图现有 `State → Failed` + 会话内错误文案；确认失败
  Tab 不是“空白可用”态，可让用户关闭。不新增大重构。

#### 4.1.4 连接中反馈

- 复用 `HasActiveSession`：会话对象一经建出即高亮行 / 卡片。
- 「最近连接」卡与首页/列表已有该态；「收藏」行本次同步补上连接中高亮（可选增强，
  若涉及收藏行也显示小绿点与最近卡一致）。

### 4.2 B 批量操作（我的连接页 + 子视图）

#### 4.2.1 多选模式 UI

- 页内工具条右侧新增 **「多选」Toggle**（Segment / Secondary 按钮 + 选中态）。
- 开启后：
  - 行首星标列临时替换为 **CheckBox**（勾选态驱动选中）；星标动作仍可从行右键 /
    ⋯ 菜单触发，避免同列双控件。
  - 行单击 = 勾选；双击 / Enter 进入多选后不再单独连接（避免歧义）。
  - `SelectionMode=Extended`，支持 Shift / Ctrl / 拖拽范围选择；`Esc` 退出多选。
  - 三个子视图（我的连接 / 收藏 / 最近连接）各自独立，切换视图或退出多选即清空
    选择。
- 开启后列表顶部浮现**批量动作条**：
  `已选 N`　`全选` / `清除`　`连接`　`收藏`(整体开关)　`移到分组 ▾`
  `标签 ▾`(增/删)　`删除`(危险，强确认)。

#### 4.2.2 ViewModel 支撑（ConnectionsPageViewModel）

- 新增：
  - `IsMultiSelect`（[ObservableProperty]）与相关命令（EnterMultiSelect/ExitMultiSelect、
    全选/清除、ToggleAllFavorite、批量移动/标签/删除、批量连接）。
  - 选中集合：直接使用列表 `SelectedItems`（ICollectionView/ListBox）或维护
    `ObservableCollection<ConnectionItemViewModel> SelectedConnections`。
- 批量动作作用域 = 当前筛选后可见集的已选项；删除强确认文案复用现单条删除并升级为
  “将删除 N 个连接”，明确不影响其引用凭据。
- 批量标签：增删用一个集合 diff（多选设备共享标签则并入，不共享则整体设置/清空？），
  首版取简单语义：选多个标签应用到所有已选 + “清除所选标签”可选——见实现计划落定
  交互细节，避免过度设计。
- 批量连接逐个调 `OpenSessionAsync`（已开设备自动聚焦，天然与 A 一致）。

### 4.3 C 首页收藏行可连接

- 「收藏」行 DataTemplate（HomePage `FavoriteRow` 与「我的连接」收藏视图共用
  `ConnRowTemplate`，是两套不同模板）分别补**双击 = 发起连接**：
  - HomePage `FavoriteRow`：包一层双击事件 → `HomePageViewModel` 转发到统一漏斗。
  - 我的连接收藏视图行：沿用页面列表既有双击逻辑（已走统一漏斗）。
- 单击不连接（不误触），与「我的连接」约定一致。
- 首页最近活动行是历史记录、不含连接 Profile，本轮不支持重连，标注为已知边界。

## 5. 影响文件（预计，实现以计划为准）

- 链路：`src/RemoteFlow.Application/Services/SessionManager.cs`、`MainViewModel.cs`、
  首页/连接页 VM 与 code-behind、相关 XAML。
- 批量：`ConnectionsPage.xaml(.cs)`、`ConnectionsPageViewModel.cs`、（分组/标签）
  复用 `ConnectionService`/`GroupService` 批量路径，视需要加服务层批量方法。
- 首页收藏双击：`HomePage.xaml(.cs)`、`HomePageViewModel.cs`。
- 版本：`Directory.Build.props` → 0.4.0。

## 6. 不做（YAGNI）

- 不做“常驻勾选列”；不做多 Tab 排序/固定；不做会话 Tab 常驻空态改造；
  不做历史/最近活动重连（除非后续单列）。
- 不做批量连接排队/串行进度长列表的精细展示，首版逐个发起即可。

## 7. 测试与验证

- 单元/集成：`SessionManager` 同 Profile 去重（二次请求不新建 / 聚焦）、创建中占位
  清理、并发上限 + 占位交互；`ConnectionService`/`GroupService` 批量（收藏开关、移
  分组、增删标签、删除）路径。
- 手动：首页最近卡 / 收藏行 / 我的连接行三者触发连接行为一致；连点同设备不产生
  第二个 Tab；批量多选四种动作；RDP / VNC / SSH 运行时仍需实机确认。
- Build 0 警告 0 错误；回归既有 82 项测试。
