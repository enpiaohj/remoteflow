# RemoteFlow v0.22.0 玻璃外观说明

- 文档版本：v1.0
- 日期：2026-09-27
- 适用软件版本：RemoteFlow v0.22.0（Windows）；macOS 未改动
- 读者：RemoteFlow 用户、贡献者

---

## 1. 概览

v0.22.0 让主窗口与对话框使用 Windows 11 的系统材质，面板变为半透明，形成统一的玻璃外观。

| 项 | 说明 |
| --- | --- |
| 设置位置 | 设置 → 常规 → 外观与行为 →「窗口材质」「透明度」 |
| 材质 | 亚克力（默认）/ 云母 / 纯色 |
| 透明度 | 0–100%，步进 5，默认 50，拖动实时预览 |
| 系统要求 | Windows 11 22H2（build 22621）及以上；更低版本自动保持纯色 |

---

## 2. 材质选项

| 材质 | 效果 | 适合 |
| --- | --- | --- |
| 亚克力 | 模糊透出窗口后方的窗口与桌面，玻璃感最强 | 想要明显的玻璃效果 |
| 云母 | 只随桌面壁纸淡淡透色，不透出其它窗口 | 喜欢克制、接近系统设置 / 文件资源管理器 |
| 纯色 | 不使用系统材质，与 v0.21.0 外观完全一致 | 远程桌面性能敏感、或偏好实色 |

对话框与浮层（连接 / 凭据 / 分组 / 标签编辑器、主机密钥、测试连接、消息、口令、标签管理、连接质量浮层）
在亚克力或云母下统一使用亚克力，圆角与阴影由系统绘制；纯色下保持原样。

以下情况由 Windows 自动显示为纯色，属于系统行为：关闭了「设置 → 个性化 → 颜色 → 透明效果」、
节能模式、窗口失去焦点时（亚克力会淡化）。在远程桌面会话中实测亚克力与云母均可正常显示。

---

## 3. 透明度

透明度只调节三层半透明面，其余保持不变：

| 层 | 覆盖范围 | 随透明度变化 |
| --- | --- | --- |
| 窗口底 | 标题栏、左侧图标栏、连接资源列、状态栏下方的亮度薄涂 | 是 |
| 工作区面板 | 中央工作区、右侧详情面板 | 是 |
| 卡片 | 列表、首页卡片、设置卡片等 | 是 |
| 弹出层 | 右键菜单、下拉框、提示、会话选择器 | 否（始终近乎不透明，避免透出下方文字） |
| 文字与状态色 | 全部文字、协议 / 状态 / 品牌色 | 否 |

- 0%：接近实色；50%：默认设计值；100%：玻璃感最强，但仍保留一层薄涂。
- 越透明，窗口后方内容越明显；后方内容特别亮或特别暗时文字对比度会下降，可按需要调低。
- 玻璃外观下，浅色主题的二 / 三级文字各加深一档，深色主题的三级文字提亮一档。默认透明度下实测最坏情况：
  浅色三级文字约 3.2:1、正文 10:1 以上；深色 5.4:1 以上。

---

## 4. 不透明的区域（技术限制）

会话画面始终不透明：RDP（系统远程桌面控件）、SSH 终端（WebView2）、VNC 画面都是内嵌的原生窗口，
WPF 无法让它们透明或在其上叠加材质。会话标签、标题栏、状态栏等外框仍是玻璃外观。

---

## 5. 实现要点（贡献者）

| 位置 | 作用 |
| --- | --- |
| `src/RemoteFlow.App/Services/WindowBackdrop.cs` | 系统材质接线：DWM 整窗扩展边框、合成目标透明、`DWMWA_SYSTEMBACKDROP_TYPE`；`Attach` / `Refresh` / `PrepareDialog` |
| `src/RemoteFlow.App/Services/GlassTransparency.cs` | 透明度 → 三层 Alpha 的线性插值（50 = 设计值） |
| `src/RemoteFlow.App/Services/ThemeService.cs` | 玻璃覆盖层合并在调色板之后，随深浅色 / 材质 / 透明度重建 |
| `src/RemoteFlow.App/Themes/Glass.Light.xaml` / `Glass.Dark.xaml` | 玻璃覆盖层（只覆盖「面」的语义键与少量文字色） |

- **不使用 WPF 分层透明**（`AllowsTransparency`）：它会拖慢渲染并破坏 RDP / WebView2 等内嵌原生窗口，且 DWM
  不会为分层窗口绘制系统材质。对话框在玻璃外观下于显示前改为普通窗口，去掉自绘阴影边距与圆角。
- **标题按钮**：扩展边框后系统会在自绘按钮下再画一套最小化 / 最大化 / 关闭按钮，通过移除 `WS_SYSMENU` 消除；
  标题栏右键系统菜单与 Alt+F4 实测仍可用。退出无边框全屏还原窗口样式后调用 `WindowBackdrop.Refresh` 重新套用。
- **新增语义键**：`Bg.Chrome`、`Bg.Workspace`、`Bg.Popup`，纯色调色板中与 `Bg.Layer` 同色，保证纯色外观不变
  （有回归测试约束）。

## 6. 设置与兼容

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| `WindowMaterial` | `Acrylic` | `Solid` / `Mica` / `Acrylic` |
| `WindowTransparency` | `50` | 0–100，超出范围按边界处理 |

从旧版本升级后设置文件中没有这两项，按默认值启用亚克力；可在设置中改回纯色。数据库结构无变化。

---

## 7. 已知问题

- 会话画面始终不透明（见第 4 节）。
- 页面切换后新页面内容不在 UI 自动化（辅助功能）树中，屏幕阅读器可能读不到（既有问题，非本版引入）。
- 会话完全全屏的进入 / 退出未在玻璃外观下做自动化验证。
- macOS 无玻璃外观设置。
