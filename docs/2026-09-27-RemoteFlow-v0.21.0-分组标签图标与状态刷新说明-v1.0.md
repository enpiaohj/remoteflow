## 2. 图标体系

### 2.1 设备类型（主图标）

设备类型描述「这是一台什么设备」，与连接协议相互独立（例如一台 Linux 服务器可以同时有
SSH 与 VNC 两个连接）。在「新建 / 编辑连接」对话框的「设备类型」中选择。

| 设备类型 | 典型用途 |
| --- | --- |
| Windows 电脑 | 办公桌面、个人 PC |
| Windows 服务器 | Windows Server 业务主机 |
| Linux 服务器 | 通用 Linux 主机 |
| 域控 | Active Directory 域控制器 |
| 文件服务器 | 文件共享 / NAS |
| macOS 设备 | Mac 电脑（屏幕共享 / VNC） |
| Web / 应用主机 | Web 服务、应用服务器 |
| 数据库服务器 | MySQL / SQL Server / PostgreSQL 等 |
| 网络设备 | 交换机、路由器、防火墙 |
| 虚拟机 | Hyper-V / VMware / KVM 虚拟机 |
| 容器 | 容器宿主或容器实例 |
| 云主机 | 公有云 / 私有云实例 |

**未指定时按协议推断**，存量连接升级后外观不变：

| 协议 | 推断的设备类型 |
| --- | --- |
| RDP | Windows 电脑 |
| SSH | Linux 服务器 |
| VNC | macOS 设备 |

设备图标出现的位置：连接列表、详情面板、首页最近连接卡片 / 收藏 / 最近活动、
会话标签、会话选择器、测试连接对话框。

### 2.2 协议徽章

| 协议 | 颜色 | 图形 |
| --- | --- | --- |
| RDP | 蓝 | 显示器 |
| SSH | 绿 | 终端 |
| VNC | 紫 | 显示器 |

徽章 = 协议色小方块内白色矢量图形 + 协议缩写。列表、详情、首页共用同一模板。

### 2.3 连接状态

| 状态 | 颜色 | 含义 |
| --- | --- | --- |
| 在线 | 绿 | TCP 探测可达（没有活动会话） |
| 已连接 | 蓝 | 存在已建立的会话 |
| 连接中 / 重新连接中 | 琥珀 | 会话正在建立或自动重连 |
| 异常 | 红 | 会话连接失败 |
| 离线 | 灰 | TCP 探测不可达（「现在不通」不视为错误，不用告警色） |
| — | 灰 | 尚未探测或探测已关闭 |

优先级：已连接 > 连接中 > 异常 > 在线 / 离线。绿色只表示「可达」，不表示「已连接」。
会话标签、标题栏状态入口、底部状态栏圆点使用同一套颜色；会话断开（已断开）为灰色，
由会话内的断线状态层提示「重新连接」。

### 2.4 连接资源智能视图

| 视图 | 图标 |
| --- | --- |
| 所有设备 | 显示器 + 服务器组合 |
| 收藏 | 琥珀色星标 |
| 最近连接 | 蓝色历史时钟 |

资源列尺寸：智能视图图标 18 px、行高 32 px；分组图标 16 px、行高 28 px；各行计数统一右对齐。

## 3. 分组

### 3.1 两个永久内置分组

| 能力 | 我的设备 | 未分组 | 自定义分组 |
| --- | --- | --- | --- |
| 改名 | 否 | 否 | 是 |
| 更换图标 | 否（固定蓝色设备图标） | 否（固定灰色收纳图标） | 是（12 种） |
| 删除 | 否 | 否 | 是（组内连接移到「未分组」，子分组提升一级） |
| 移动层级 | 否（固定根级） | 否 | 是 |
| 新建连接到该组 | 是 | 是 | 是 |
| 新建子分组 | 是 | 否 | 是 |
| 默认新建连接分组 | 是（固定） | 否 | 否 |
| 参与云同步 | 是 | 否（本机兜底分组） | 是 |

已移除的入口：分组右键「设为默认分组」、设置页「保护默认分组」开关、删除默认分组后
重新选择默认分组的流程（Windows 与 macOS 均已移除）。内置分组的右键菜单只保留
「新建连接」「新建子分组」（「未分组」只有「新建连接」）。

### 3.2 自定义分组图标

右键分组 →「编辑分组」，在同一对话框中修改名称与图标（带实时预览）；新建分组默认「文件夹」。

可选图标：文件夹、公司、数据中心、服务器机架、云环境、网络、数据库、Web 服务、安全、开发、
实验室、归档。图标颜色按分组稳定分配（蓝 / 紫 / 绿 / 橙 / 灰），同一分组在各设备上颜色一致。

### 3.3 升级时的自动校正

每次启动及进入连接工作台时，应用会校正内置分组：

1. 确保「未分组」存在，并固定名称、图标与系统身份。
2. 选出唯一的内置「我的设备」，优先级：已标记内置 → 旧版默认组 → 名称为「我的设备」的
   根级分组 → 都没有则新建。同一优先级内按分组 Id 排序取第一个，**多台设备独立运行也会
   选中同一个分组**。
3. 选中的分组沿用原有 Id，连接和子分组的引用无需迁移；名称、图标、位置与默认 / 保护标记被校正。
4. **合并重复的「我的设备」**：若根级还存在其它名为「我的设备」的普通分组（常见于多台设备
   各自首次启动后经云同步汇合），其连接与子分组并入内置组（子分组重名时追加「(2)」等序号），
   然后删除已清空的重复组。**不会删除任何连接**，每一步变更都会登记云同步，其它设备随之收敛。

> 建议：升级前备份 `%LOCALAPPDATA%\RemoteFlow\remoteflow.db`。合并会改变原有的分组划分，
> 连接本身不受影响。

### 3.4 云同步规则

- 分组与标签的同步 Schema 升级为 v2，可读取旧版本 payload。
- 远端不能删除、改名、移动或更换内置「我的设备」的图标。
- 只有显式声明（新版本的「内置」标记或旧版本的「默认」标记）才会被视为内置候选；
  **不再仅凭名称提升**，避免「提升 → 本地降级 → 推送 → 再提升」的来回翻转。
- 多个内置候选由 3.3 的规则确定性收敛为一个。

## 4. 标签

- 每个标签由名称、颜色、图标、描述组成。
- 可选图标：标签、生产、测试、重要、安全、位置、项目、团队、网络、维护。
- 颜色：预设色板或自定义 `#RRGGBB`。
- 编辑入口：连接编辑器「管理…」或标签管理对话框；编辑器中切换图标 / 颜色时顶部预览实时更新。
- 显示位置：标签管理列表、连接编辑器标签选择、连接列表标签列、详情面板、标签筛选下拉。
  图标以标签颜色着色。
- 旧数据默认显示「标签」图标；标签图标随云同步。

## 5. 页面刷新与在线探测

### 5.1 刷新时机

| 操作 | 行为 |
| --- | --- |
| 切换到另一个页面（鼠标、键盘、辅助工具均可） | 完整刷新目标页 |
| 再次点击当前页的导航按钮 | 回到工作区并完整刷新 |
| 从会话标签切回工作区 | 轻量刷新：首页重读列表但不重新探测；连接列表不重建（会话状态本就实时同步）；凭据 / 设置照常刷新 |
| 停留首页时会话状态变化 | 约 150 ms 去抖后刷新列表与会话状态，在线状态沿用上次探测结果 |
| 快速连续切页 | 取消上一次加载，丢弃过期结果，不显示错误横幅 |

各页刷新内容：

| 页面 | 刷新内容 |
| --- | --- |
| 首页 | 连接 / 最近活动 / 会话状态 + 在线探测 |
| 连接工作台 / 收藏 / 最近连接 | 凭据名称、连接列表、分组树 + 在线探测 |
| 凭据 | 凭据列表与引用计数 |
| 设置 | 已信任主机密钥 |
| 帮助 / 关于 | 静态页，不访问数据库 |

### 5.2 在线探测

- 方式：对「主机:端口」做一次 TCP 连接尝试，能建立即「在线」。
- 单次超时 1.5 秒，最多 8 个并发。
- 首页对「最近连接」与「收藏」按连接去重，同一设备只探测一次，两处同时更新。
- 由设置中的「连接工作台在线探测」开关统一控制（首页同样遵循）；关闭后状态显示「—」，
  连接工作台仍可用工具条「探测」手动触发。
- 悬停状态可查看探测时间（「探测于 日期 时间」）。

## 6. 会话标签

- 标签头：设备图标 + 名称 + 状态圆点 + 关闭按钮；未选中标签的图标略淡。
- 悬停提示：`名称 · 协议 · 状态`，例如 `web01 · SSH · 已连接`。
- 右键菜单：重新连接 / 关闭会话（`Ctrl+W`）/ 关闭其他会话 / 关闭右侧会话 / 关闭全部会话。
- 紧凑模式：会话达到 5 个或标题栏放不下时，Tab 条切换为「当前会话」下拉选择器；
  支持 ↑ / ↓ 移动、Enter 切换、Delete 关闭、Esc 收起，行内第二行显示「主机 · 协议」。

## 7. 右键菜单分隔线规则

菜单按上下文隐藏部分菜单项时（例如内置分组没有编辑 / 删除），分隔线按以下规则整理：
只有上下都有可见菜单项时才显示；连续多条只保留一条；不出现在菜单首尾。适用于分组、
连接行、首页行三类右键菜单（实现：`src/RemoteFlow.App/Views/ContextMenuSeparators.cs`）。

## 8. 程序图标

### 8.1 设计

「端点连接流」：蓝—靛渐变圆角底；左下与右上两个白色设备端点，由青蓝流线贯通，
流线末端为向前箭头，线上三颗节拍点表达数据流动。大尺寸带克制的高光、内描边与投影；
16 / 24 / 32 px 使用单独简化字形（去高光投影、加粗主轮廓），保证小尺寸清晰。
图形为原创，不含第三方图标素材。

### 8.2 生成

```powershell
python scripts/build-appicon.py          # 生成全部资源并自校验
python scripts/build-appicon.py --check  # 只校验已生成资源
```

依赖 Python 3 与 Pillow（仅开发期使用，不进入应用运行依赖）。`scripts/build-appicon.sh`
为同一脚本的 Shell 入口。

| 输出 | 位置 | 内容 |
| --- | --- | --- |
| Windows 程序图标 | `src/RemoteFlow.App/Assets/RemoteFlow.ico` | 16 / 24 / 32 / 48 / 64 / 128 / 256 七帧 |
| Windows Logo | `src/RemoteFlow.App/Assets/RemoteFlow-logo.png` | 256 px，标题栏、侧栏、关于页、设置页使用 |
| macOS iconset | `src/RemoteFlow.App.Mac/Resources/AppIcon.iconset/` | 16–1024 px 共 10 张 |
| macOS 图标 | `src/RemoteFlow.App.Mac/Resources/AppIcon.icns` | Bundle 图标 |

Windows 帧比 macOS 裁掉更多留白（底座约占画布 91%），macOS 保留 Apple 规范留白。
校验项：各帧尺寸、四角透明、可见像素比例。

## 9. 数据与兼容性

| 项 | 说明 |
| --- | --- |
| 数据库 Schema | v5 → v7。v6 新增 `connections.device_type`；v7 新增 `connection_groups.is_built_in`、`tags.icon`。均为加列迁移，存量数据不变 |
| 降级 | 升级到 v0.21.0 后，旧版本会因数据库版本更高而拒绝打开（防止损坏数据）。如需回退，请恢复升级前的数据库备份 |

| 设置文件 | 旧的「保护默认分组」相关设置不再使用，保留在文件中不影响运行 |
