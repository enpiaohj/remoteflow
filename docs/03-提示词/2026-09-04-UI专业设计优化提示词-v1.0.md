# UI 专业设计优化提示词

请对当前项目现有 UI 再进行一轮专业级设计优化。

这次希望你充分发挥自己的产品设计、UI/UX 和视觉设计能力，不需要严格遵循固定设计规则，也不要被现有样式限制。

目标是：

在保留现有核心功能和业务逻辑的前提下，把当前 UI 提升到成熟商业软件的设计水平。

请先完整查看当前项目、现有页面、交互流程和组件实现，再自行判断目前 UI 存在哪些问题，以及最值得优化的地方。

你可以主动调整：

- 页面布局
- 信息层级
- 视觉风格
- 色彩
- 字体
- 间距
- 图标
- 卡片
- 列表
- 按钮
- 状态展示
- 空状态
- 交互反馈
- 窗口比例
- 细节质感

不要求沿用当前设计方案。

如果你认为某些区域需要重新设计，可以直接重新设计。

如果现有设计已经合理，也不要为了修改而修改。

整体希望达到：

- 简洁
- 现代
- 专业
- 高级
- 清晰
- 有产品感
- 长时间使用舒服
- 像成熟商业软件，而不是 Demo 或 AI 自动生成的界面

尤其关注第一眼的整体观感和产品质感。

请以真正的软件产品设计师视角进行判断，而不是单纯修改 CSS、颜色或圆角。

你可以参考当前优秀桌面软件和现代专业工具类应用的设计思路，但不要机械模仿某一个产品。

本次请直接完成设计和代码落地，不要只给建议。

完成后自行再次审视整个 UI，如果第一版仍有明显不协调、普通、廉价或不够成熟的地方，请继续进行第二轮精修。

最终目标只有一个：

让当前产品看起来明显比现在更专业、更成熟、更漂亮，并且让用户第一眼就能感受到设计质量的提升。

注意不要破坏现有已经正常工作的核心功能。

完成后告诉我：

1. 你认为原 UI 最大的问题是什么
2. 这次采用了什么设计方向
3. 重点修改了哪些区域
4. 哪些地方是你主动重新设计的
5. 还有没有你认为值得继续优化的地方
