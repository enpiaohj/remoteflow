# RemoteFlow V0.1.0 — SSH / VNC 人工测试清单

## 前置

- [ ] 一台可 SSH 的 Linux 主机（准备好 Password 与 Private Key 两种登录方式）

- [ ] 本机已安装 Microsoft Edge WebView2 运行时（Windows 11 通常已内置）

## SSH

### 连接与认证
- [ ] 用 Password 凭据连接，终端出现远端 shell 提示符
- [ ] 用 Private Key 凭据连接（含 / 不含 Passphrase 两种）
- [ ] 错误密码 → 会话内提示「身份验证失败」，不弹模态框
- [ ] 不可达主机 → 提示「无法连接」，可点「重新连接」

### Host Key
- [ ] 首次连接弹出指纹确认框，点「信任并继续」后连上；设置页出现该主机记录
- [ ] 手动改动服务器 host key 后再连 → 弹「主机密钥已变更」强警告，默认焦点在「取消连接」
- [ ] 设置页移除该 host key 记录后再连 → 重新弹首次确认框

### 终端行为
- [ ] 输入中文、`ls --color` 彩色输出、`vim` 全屏应用正常
- [ ] 拖动窗口改变大小 → `tput cols` / `tput lines` 跟随变化（远端 SIGWINCH）
- [ ] Ctrl+C 中断、Ctrl+Z 挂起、Tab 补全、方向键历史正常
- [ ] 工具条「复制」：选中终端文本后点按钮 → 内容进入剪贴板
- [ ] 工具条「粘贴」：剪贴板有文本时点按钮 → 文本作为输入送入远端
- [ ] KeepAlive：设置一个较短间隔，空闲数分钟后会话不被中间设备断开

### 多会话与全屏
- [ ] 同时开 2 个 SSH 会话，切换 Tab 互不影响，各自独立
- [ ] 工具条「全屏」按钮 → 窗口铺满屏幕，无左侧空白，终端撑满
- [ ] F11 在终端有焦点时也能切全屏；Esc 若被终端消费属正常，用 F11 / 按钮退出
- [ ] 关闭会话 Tab → 该 SSH 连接断开，其他会话不受影响
- [ ] 关闭应用（优雅退出）→ 所有 SSH 会话断开，日志无 Error/Fatal

### 安全
- [ ] 连接历史里只有主机 / 协议 / 时间 / 结果，无密码或私钥
- [ ] `%LOCALAPPDATA%\RemoteFlow\logs\*.log` 全文搜索密码字符串 → 搜不到

## VNC / macOS 屏幕共享

### 连接与认证
- [ ] 用 VNC 密码凭据连接，出现远端桌面画面
- [ ] 错误密码 → 会话内提示，不弹模态框
- [ ] 连接 macOS「屏幕共享」（端口 5900）正常

### 画面与输入
- [ ] 鼠标移动 / 点击 / 拖拽 / 滚轮在远端正确响应
- [ ] 键盘输入（含中文经输入法）正确送达远端
- [ ] 特殊键：方向键、Home/End、F1–F12、Delete 正常
- [ ] 工具条「适应窗口 / 1:1」切换：适应窗口时画面缩放填充；1:1 时原始像素、超出可滚动
- [ ] 「只读模式」连接：能看画面，键鼠不影响远端
- [ ] 远端分辨率变化（如远端插拔显示器）→ 画面自动重建，不崩

### 全屏与多会话
- [ ] 工具条「全屏」按钮 → 铺满屏幕，无左侧空白，画面按当前缩放模式填充
- [ ] 同时开 RDP + SSH + VNC 三个会话，切 Tab 都不断线
- [ ] 关闭 VNC 会话 → 后台线程与位图资源释放（任务管理器内存不持续增长）
- [ ] 优雅退出应用 → 所有会话断开，日志无 Error/Fatal

### 安全
- [ ] 导出 CSV → 打开确认无任何密码字段
- [ ] 日志不含 VNC 密码
